# principle候选 块P3 (第5章)

- id: pC3-01
  title: 有效贴现因子: 存续概率乘入时间偏好; 无限期/有限期模型的判别
  type: calculation
  source_chapter: 5.1.1
  source_quote: |
    贴现因子还能表示博弈在每一期期末结束的可能性:假定对时间的偏好率是 r,每期长度是 Δ,博弈从某一期延续到下一期的概率为 μ。……那么期望的贴现价值就是 δ' = μδ。因此,这一情形和 μ' = 1,r' = r - ln(μ)/Δ 一样。这说明无限期博弈可涵盖以概率 1 在有限期内终止的博弈。无限期和有限期的关键区别在于博弈延续到下一期的条件概率的下界是否大于 0。
  summary: |
    δ有两个可互换解释: 纯时间偏好(δ=e^{-rΔ})与关系存续概率(δ'=μδ), 二者可合并。配套判别规则(转写稿明示): 无限期模型适合"参与人总是认为博弈有很大的概率多延续一期"的情况; 有限期模型适合"容易共同预见到博弈何时结束"的情况。
    inputs: r(时间偏好率/利率, 1/期), Δ(每期长度), μ(关系延续到下一期的概率)。
    formula: δ=e^{-rΔ}; 有效贴现因子δ'=μ·e^{-rΔ}; 等价利率 r'=r-ln(μ)/Δ。
    units: δ无量纲∈[0,1); r、r'为每期比率。
    output: 用于无名氏定理与合作条件判别的"有效耐心"δ。
    missing_conditions: μ需外生估计(退出/倒闭/合同到期风险), 转写稿未给估计方法; 要求各期存续结构同分布; 脚注60口径——行动连续统时延续概率收敛于0但收敛足够慢仍可有合作均衡(Bernheim)。
    投资映射: 评估客户关系/供应商/合谋圈的合作可持续性时, 先把退出、倒闭、到期风险折进有效δ(存续概率低的主体"有效耐心"低)。
  tags: [贴现因子, 合谋可持续性, 建模口径]
  task_ids: [task-01]

- id: pC3-02
  title: 静态均衡永续重复必为子博弈完美; δ足够小时唯一均衡
  type: rule
  source_chapter: 5.1.1
  source_quote: |
    如果 α* 是阶段博弈的纳什均衡(即"静态均衡"),那么策略组合"每个参与人 i 从现在开始一直选择 α_i*"是一个子博弈完美均衡。……如果贴现因子足够小,重复博弈中唯一的一类纳什均衡就是对每段以正概率出现在均衡中的历史都指定一个静态均衡。
  summary: |
    判断规则: (1)只要阶段博弈有纳什均衡, "每期一直重复它"就是重复博弈的SPE——重复博弈不缩小均衡收益集合; 有m个静态均衡时, 任意按时段轮换组合α^{j(t)}也都是SPE(开环策略)。(2)若δ足够小(未来不重要), 唯一纳什均衡就是逐段指定静态均衡。口径: 无限策略空间时须修正——即使未来惩罚很小也可能使参与人放弃很小的当期收益。
    投资映射: 高利率、快周转、临近到期的"短视"行业或关系中, 价格/产量行为可先用"阶段博弈均衡的简单重复"作基准预测; 偏离该基准才需要寻找支持合作的奖惩机制。此规则给出下限基准而非上限。
  tags: [纳什均衡, 基准预测, 贴现因子]

- id: pC3-03
  title: 最小最大值(保留效用)的定义与计算要点
  type: calculation
  source_chapter: 5.1.2
  source_quote: |
    定义参与人 i 的保留效用或最小最大值为 \underline{v}_i = \min_{\alpha_{-i}} [ \max_{\alpha_i} g_i(\alpha_i, \alpha_{-i}) ] 这是参与人 i 的对手选择任何 \alpha_{-i} 时,只要参与人 i 正确预见到 \alpha_{-i} 并对它作出最佳反应就能得到收益的下限。
  summary: |
    保留效用=对手以最大化伤害为目的选择策略时, i仍能保证的每期收益; 它是重复博弈一切均衡收益的下界, 也是"惩罚后能被压到的最低收益"。
    inputs: 阶段博弈收益函数g_i(需成本/需求参数); 允许对手使用混合策略。
    formula: v_i = min_{α_{-i}} max_{α_i} g_i(α_i, α_{-i}); 取最小值的对手策略组合记m_{-i}^i(最小最大组合, 可能不唯一, 图5-1例中是一个概率区间)。
    units: 与阶段博弈收益同单位(每期流量)。
    output: 参与人i的均衡收益下界v_i。
    missing_conditions: 需要阶段博弈收益数值; 计算要点(图5-1示例明示)——若把对手限制在纯策略, 最小最大值会被高估(该例纯策略下为1, 混合下降到0), 从而低估可行合作区间; 对手可以随机化是默认口径。

- id: pC3-04
  title: 均衡收益下界规则: 任何均衡收益不低于最小最大值
  type: rule
  source_chapter: 5.1.2
  source_quote: |
    无论贴现因子有多大,参与人 i 在任何静态均衡和任何重复博弈的纳什均衡中都至少得到收益 \underline{v}_i。……从而,我们先验地知道了重复博弈中没有均衡能给任何参与人带来低于其最小最大值的收益。
  summary: |
    判断规则: 先算各方最小最大值, 则任何可想象的均衡(静态或重复、无论δ多大)中每方收益≥其v_i。论证思路: 参与人总可"短视地"每期对对手策略作当期最优反应, 每期至少得v_i。适用边界(转写稿明示): 当行动只被不完美观察时(5.5节)此结论可能失效——短视策略不再保证每期≥v_i。
    投资映射: 谈判与合谋分配的底线核算——对手永不接受低于其"自保收益"的份额; 公司的退出选项价值≈其最小最大值。识别谈判区间: [各方最小最大值, 可行集帕累托边界]。
  tags: [最小最大值, 收益下界, 谈判底线]
  task_ids: [task-01]

- id: pC3-05
  title: 无名氏定理(纳什版): 耐心+可行+严格个人理性⇒几乎任何收益可实施
  type: rule
  source_chapter: 5.1.2
  source_quote: |
    重复博弈的"无名氏定理"认为,如果参与人有足够的耐心,那么任何可行的个人理性收益都能在均衡中得以实施。……对每个满足条件"$v_i > \underline{v}_i$ 对所有参与人 $i$ 成立"的收益向量 $v$,存在 $\underline{\delta} < 1$,使得对所有 $\delta \in (\underline{\delta}, 1)$ 存在纳什均衡 $G(\delta)$,其收益为 $v$。
  summary: |
    条件→结论: (1)目标收益v可行(阶段博弈收益的凸包内); (2)严格个人理性(v_i>最小最大值); (3)δ∈(δ*,1)。则v可由纳什均衡实施; 所用策略是"冷酷的": 一次背离后永久最小最大惩罚。备注(原文): 直观是耐心参与人眼中"背离引起的未来每一期的效用损失要超过背离时任何有限一期的收益增量,即使损失很小"。口径: 若v需公共随机化实现, δ*更大(用式5.6); 此为纳什均衡版, 惩罚只须"被畏惧"不须"被执行", SPE版本见pC3-07/09。
    适用边界: 重复博弈不能建模"过去影响未来可行集/收益"的现象(生产性投资、学习)——转写稿开篇明示。
    投资映射: 只要有耐心+背叛可识别+惩罚被畏惧, 几乎任何分配(合谋价格、份额、条款)都可能是稳定结果; 预测竞争行为时不能只盯"竞争均衡"一个点。
  tags: [无名氏定理, 冷酷策略, 合谋可持续性]
  task_ids: [task-01]

- id: pC3-06
  title: 临界贴现因子δ*的计算(合谋/合作可持续阈值)
  type: calculation
  source_chapter: 5.1.2
  source_quote: |
    $(1-\underline{\delta}_i)\max_a g_i(a) + \underline{\delta}_i\underline{v}_i = v_i$……由于 $v_i > \underline{v}_i$,方程(5.5)的解 $\underline{\delta}_i$ 就小于 1。取 $\underline{\delta} = \max_i \underline{\delta}_i$ 完成上述讨论。
  summary: |
    支撑目标收益v的临界贴现因子: 背离当期最大收益与之后永久受罚的等价交换点。
    inputs: v_i(目标合作/合谋收益, 每期标准化), max_a g_i(a)(单期最大背离收益), \underline{v}_i(受罚后每期收益=最小最大值)。
    formula: 由(5.5)解出 δ*_i = (max_a g_i(a) - v_i)/(max_a g_i(a) - \underline{v}_i); 取 δ* = max_i δ*_i。
    units: 无量纲; 各输入为每期标准化收益(每期1单位效用标准化为1)。
    output: 临界贴现因子δ*; δ>δ*时合谋v可由纳什均衡支撑。
    missing_conditions: 需估计三个收益数值(行业需求弹性、成本结构、份额分配); 这是纳什版阈值——SPE版(Friedman, pC3-07)把\underline{v}_i换成静态均衡收益e_i; 用公共随机化实现v时阈值条件改用(5.6)式且更高。
    投资用法: 对候选行业估三数(合谋利润、背叛利润、惩罚利润), 套公式得δ*, 与行业"有效耐心"(利率+存续概率+发现速度, 见pC3-01/08)比较, 即得合谋可持续性判断。
  tags: [临界贴现因子, 合谋条件, 计算规则]

- id: pC3-07
  title: Friedman纳什威胁定理: 以静态均衡为惩罚的子博弈完美合谋
  type: rule
  source_chapter: 5.1.2
  source_quote: |
    令 $\alpha^*$ 是一个收益为 $e$ 的静态均衡(一个阶段博弈的均衡)。那么对任何 $v \in V$,其中 $v_i > e_i$,对所有参与人 $i$ 成立,存在一个 $\underline{\delta}$ 使得对所有 $\delta > \underline{\delta}$,存在一个子博弈完美均衡 $G(\delta)$,其收益为 $v$。
  summary: |
    条件→结论: 用阶段博弈静态均衡收益e(而非最小最大值)作惩罚点, 只要v_i>e_i且δ够大, "合作→有人背离→永久回到α*"是SPE; 因惩罚路径本身是均衡, 惩罚可信(这是它优于纳什无名氏定理构造之处)。条件式(5.7): (1-δ)max_a g_i(a)+δe_i<v_i。
    经典应用(转写稿明示): 有耐心的古诺双寡头"隐性共谋"——各自生产垄断产出的一半, 任何背离触发永久古诺竞争; 合谋无合同执行, 靠害怕触发古诺竞争维持。
    边界: 若存在使所有参与人得到其最小最大值的静态均衡(囚徒困境、完全替代+规模报酬的伯特兰), 结论加强到无名氏定理水平; 否则弱于它。
    投资映射: 判断行业能否隐性合谋→先找阶段博弈均衡(古诺/伯特兰)作惩罚点, 估合谋利润与背叛利润差, 套用pC3-06的阈值逻辑。
  tags: [纳什威胁, 隐性合谋, 触发策略]

- id: pC3-09
  title: 完美无名氏定理与充分维数条件
  type: rule
  source_chapter: 5.1.2
  source_quote: |
    假设可行收益集 $V$ 的维数等于参与人的个数,那么,对所有参与人 $i$ 和任何 $v_i > \underline{v}_i$ 的 $v \in V$,存在一个贴现因子 $\underline{\delta} < 1$,使得对所有 $\delta \in (\underline{\delta}, 1)$ 存在一个子博弈完美均衡 $G(\delta)$,其收益为 $v$。
  summary: |
    条件→结论: 在纳什无名氏定理基础上把均衡概念加强到子博弈完美, 代价是"充分维数"条件——dim V = I(可行收益集维数=参与人数)。此条件下任何严格个人理性的可行收益都能由SPE实施, 惩罚方案是"惩罚+奖励"构造: 未背离者获得奖励v'(i)(其他各人+ε), 用"不给予奖励"来惩罚背离者(否则奖励会抵消惩罚)。
    备注口径: Abreu-Dutta(1990)减弱到 dim V = I-1; Smith(1990)只需V*到任意两人空间的投影是二维; 反例——三人博弈且dim V=1时无名氏定理失效。
    投资映射: 参与人数越多, 维数条件越难满足, 多边稳定合作越依赖精细的"差别化补偿"结构; 若行业内无法给每个成员安排独立的奖惩通道(同质化、无差别惩罚), 卡特尔更脆弱。
  tags: [完美无名氏定理, 充分维数, 奖励机制]
  task_ids: [task-01]

- id: pC3-10
  title: 惩罚机制的设计约束: 惩罚者成本、贴现下无限惩罚不可行、以奖励代威胁
  type: principle
  source_chapter: 5.1.2
  source_quote: |
    执行最小最大策略要求参与人 $i$ 的对手生产的产品多到足以使价格降到参与人 $i$ 的平均成本以下,但这也可能在他们自己的成本之下。……当参与人贴现他们未来的收益时,这种机制将不起作用……惩罚 $N^k$ 期不是个人理性的……必须能够提供奖励,通过不奖励参与人 $i$ 来惩罚他。
  summary: |
    三条设计规范(作者明示"应当"): (1)最小最大惩罚对执行者代价高昂(寡头中须把价格压到对手平均成本之下, 可能低于自己成本), 故"被畏惧的惩罚"未必"被执行"; (2)贴现世界中指数增长的连锁惩罚(Rubinstein, N, N², N³…期)不可行——惩罚期N^k拉长后, 执行者收益收敛到g_i(m^i)<其最小最大值, 惩罚失去个人理性; (3)因此SPE惩罚要靠奖励机制: 让"惩罚状态"里执行者反而被奖励(囚徒困境中(C,D)组合使受罚者降到最小最大值而执行者获利), 且不得给最初背离者奖励。
    投资映射: 评估公司间"报复威胁"(价格战宣言、封杀、断供)可信度时问三个问题——执行报复是否伤及自身? 报复是否无限期(长期亏损的报复不可信)? 是否存在让执行者获利的报复结构?
  tags: [惩罚机制, 可信性, 激励设计]
  task_ids: [task-01, task-02]

- id: pC3-11
  title: 最小惩罚期长度N的判别式
  type: calculation
  source_chapter: 5.1.2
  source_quote: |
    挑选 $N$ 使得对所有的 $i$, $\max_a g_i(a) + N\underline{v}_i < \min_a g_i(a) + Nv_i'$ 这个惩罚长度使得对接近 1 的贴现因子,"一次背离则 $N$ 期施以最小最大策略"比"得到一次最低收益然后得到 $N$ 期 $v_i'$"要差。
  summary: |
    有限期惩罚方案的长度条件: 惩罚期N必须长到"背离一次+受罚N期"的总收益低于"先吃一期最低收益再回合作"。
    inputs: max_a g_i(a)(单期最大背离收益), min_a g_i(a)(单期最低收益), \underline{v}_i(惩罚期每期收益), v_i'(回到合作后的每期收益)。
    formula: 由(5.8)移项 N > (max_a g_i(a) - min_a g_i(a))/(v_i' - \underline{v}_i)。
    units: N为期数(整数); 其余为每期标准化收益。
    output: 满足判别式的最小N。
    missing_conditions: 需各收益数值; 该式源自时间—平均/接近1贴现的构造(定理5.3/5.4证明), 固定δ<1时的精确条件还须比较贴现和(5.1.3用的是"一次背离检验"); 行动空间有上界时N期惩罚可能仍到不了目标强度, 须引入公共随机化(定理5.7备注)。
    投资用法: 设计或识别"有限期报复"机制(会员暂停N月、禁售N期)是否足以威慑: 所需惩罚期数≈背离超额利润÷(合作与受罚的每期收益差)。
  tags: [惩罚长度, 惩罚机制, 计算规则]

- id: pC3-12
  title: Abreu最优惩罚: 一切SPE都可由"转向最差均衡"实施
  type: principle
  source_chapter: 5.1.3
  source_quote: |

- id: pC3-22

  type: checklist
  source_chapter: 5.4.3

    判断规则(Kandori 1989a): 以Blackwell"混淆"序比较信息结构——若新公共结果是旧结果加噪声(信息变差), 则重复博弈均衡收益集严格缩小(不是不变)。直觉: 旧信号可由新信号加公共随机化合成, 故旧均衡仍可行; 但新信号可甄别信息更少, 一部分合作收益不再可实施。使用要点: (1)与pC3-27/29衔接——信息质量是连续维度的价值, 边际改善也有效; (2)比较两个监控制度(披露规则改动、审计颗粒度)时用Blackwell序判断均衡集变化方向。
    投资映射: 行业信息披露质量下降(公开报价被私有报价替代、合同条款黑箱化、协会数据停发)应被解读为该行业合作/合谋可持续性的确定性削弱信号。
