# principle候选 块P1 (00前言引言+第1章+第2章)

- id: pC1-01
  title: 先判断博弈是否零和:多数商业博弈非零和、存在共同利益区
  type: principle
  source_chapter: 引言;1.1.1
  source_quote: |
    厂商们在争夺市场份额上是相互竞争的,但在定高价上却拥有共同利益。……然而社会科学中绝大多数让人感兴趣的博弈是非零和的。
  summary: |
    内容: 分析竞争格局的第一步是判断利益结构。零和博弈(一方所得即另一方所失)是"纯粹对手"的极端情形;
    作者明确指出社会科学中绝大多数让人感兴趣的博弈是非零和的——竞争者可以在份额上对立、同时在价格上拥有共同利益。
    适用条件: 对任何行业/对手关系建模之前先行判断。
    使用要点: 投资语境下,识别"共同利益区"(如共同维持高价、共同避免产能过剩)是评估价格战概率与合谋可能性的前提;
    非零和结构意味着"合作"结果可以不靠协议、仅靠利益结构出现,也意味着把竞争对手想成死敌可能误判其行为。
  tags: [非零和博弈, 竞争格局, 价格战]
  task_ids: [task-01]

- id: pC1-02
  title: 参与人少时博弈论分析才适用;厂商少则"价格接受"假设失效
  type: rule
  source_chapter: 引言
  source_quote: |
    博弈论的观点在参与人数较少的时候更有用,因为那时参与人更有可能关心其对手。例如,在市场中厂商数目很少时,
    每个厂商的产量很可能会对市场价格产生很大的影响,因而,认为每个厂商将市场价格视为给定就不合理了。
  summary: |
    内容: 可执行的适用性判断规则——"参与人少→用博弈论;参与人多到无人能影响价格→可用价格接受(完全竞争)框架"。
    判断口径: 该厂商的产量/定价决策是否会对市场价格产生显著影响。
    使用要点: 投资者筛选行业分析工具时先用此规则:CR4高、单厂扩产能改变价格Cursor的行业必须用博弈框架;
    反之,原子化行业(农产品、大宗同质品)用供需框架即可,套博弈论是过度建模。
  tags: [适用边界, 市场结构, 完全竞争]
  task_ids: [task-01]

- id: pC1-03
  title: 自利也能产生合作行为:"不合作"不等于不合作
  type: principle
  source_chapter: 引言
  source_quote: |
    如同我们在第5章和第9章中所解释的那样,不合作的参与人仅仅受个人利益的驱使也能在一些情形下表现出"合作"的行为。
  summary: |

    并不意味着参与人不能融洽相处或总是拒绝合作;纯粹自利驱动下也能出现"合作"行为(第5章重复博弈、第9章声誉)。

    只要长期利益结构合适,自利即可维持表面合作——判断的关键是利益结构而非是否"串通"。

- id: pC1-04
  title: 绝不采用严格劣势策略
  type: maxim
  source_chapter: 1.1.2
  source_quote: |
    无论参与人1如何行动,R 向参与人2提供的收益总是严格比 M 所提供的要高。用规范的术语说,策略 M 是严格劣的。
    因此,"理性"的参与人2不应采用 M。
  summary: |
    内容: 全书最基础的行动规则:理性参与人永不采用严格劣势策略(2.1.3节重述为"理性的参与人永远不会采用严格劣势策略")。
    严格劣势=存在另一个策略(纯的或混合的)在对手任何选择下都严格更优。
    使用要点: 投资中对应"无论对手/市况如何都更差的选择应无条件排除"(如高杠杆+低流动性+单一客户);
    它也是重复剔除法的原子操作:逐轮删除严格劣势策略可缩小预测区间。
  tags: [严格劣势策略, 理性, 重复剔除]
  task_ids: [task-08]

- id: pC1-05
  title: 纯策略可能劣于混合策略——劣势检验不能只查纯策略对照
  type: rule
  source_chapter: 1.1.2
  source_quote: |
    因此,一种纯策略可能严格劣于一个混合策略,即便它不劣于任何纯策略。
  summary: |
    内容: 判断规则——检验某策略是否劣势时,对照对象必须包括混合策略;一个对每个纯策略都不劣的策略,
    仍可能被一个混合策略严格占优(图1—2:U与D各1/2的混合保证1/2收益,严格优于M的0)。
    使用要点: 做策略筛选/方案比较时,"逐个对手方案都不差"不等于"不差";
    需检查对手所有可行混合(权重组合)下的期望值,否则会漏掉被随机化方案支配的选项。
  tags: [混合策略, 劣势检验, 期望收益]
  task_ids: [task-08]

- id: pC1-06
  title: 劣势检验的口径:只需对对手纯策略验证即可覆盖混合策略
  type: rule
  source_chapter: 1.1.2
  source_quote: |
    当且仅当它对于对手的所有混合策略也满足不等式(1.1)时,策略对于对手的所有纯策略满足不等式(1.1)。
    原因是,对手采用混合策略时参与人i的收益是他在对手采用纯策略时参与人i收益的凸组合。
  summary: |
    内容: 计算口径——由于收益对对手混合概率是线性的(凸组合),"对所有混合策略占优"等价于"对所有纯策略占优"。
    因此劣势检验只需在对手纯策略集上逐列核对不等式,无需遍历连续的混合空间。
    使用要点: 这把"永不采用严格劣势策略"(pC1-04)变成可机械执行的清单:对每个候选策略,
    逐个对手纯策略比较收益,全部严格更差即剔除;任何一列不满足即非劣势。
  tags: [计算口径, 凸组合, 劣势检验]
  task_ids: [task-08]

  type: principle
  source_chapter: 1.1.2
  source_quote: |
    如果存在 1% 的机会参与人2会采用 R,那么 D 就比 U 要好。……某些博弈的分析,例如图1—4中所表现的,
    对参与人彼此作出的行为假设的不确定性非常敏感。这种"稳健性"检验——检验理论的预测如何随着模型的微小变化而变化——的思路
  summary: |
    内容: 作者明确主张对博弈论预测做"稳健性检验":图1—4中重复剔除给出唯一解(U,L),
    但只要对手有1%概率犯"错"(采用劣势策略R),D就反超U——收益取极端值(如-100)时,基于"理性是共同知识"的预测很脆弱。
    使用要点: 投资应用:凡依据"对手必然理性/必然不做蠢事"推出的行业结论(如"对手绝不降价"),
    要问:若小概率事件发生,我方持仓的损失是否极端?收益结构极端不对称时,重复剔除式推理不可直接下注。
  tags: [稳健性检验, 理性假设, 敏感性]

- id: pC1-08
  title: 决策论的比较静态不能直接照搬到博弈中(对手预期内生化)
  type: principle
  source_chapter: 1.1.2
  source_quote: |
    在博弈中,存在多个决策者,参与人对他们对手的行动的预期不是外生的。这就导致一旦我们考虑到博弈中的一种变化会改变
    所有参与人的行动这一情况,来自决策论的许多人们所熟悉的比较静态的结论就不能扩展到博弈中去了。
  summary: |
    内容: 硬性警告——单人决策中"外生参数变化→最优选择变化"的比较静态结论,在博弈中因对手行为随之改变而不成立。
    适用条件: 任何"某变量变化将如何影响公司利润"的推断,只要该行业是寡头互动,就不能只做单方推演。
    使用要点: 投资中警惕"成本下降→利润上升""需求扩张→量价齐升"式线性外推:成本冲击会同时改变对手定价与进入决策,
    均衡移动方向可能反转;必须问"对手的最优反应如何变"。
  tags: [比较静态, 内生预期, 分析禁忌]
  task_ids: [task-01, task-11]

- id: pC1-09
  title: 博弈中主动缩小自身选择集/恶化自身收益反而可能获利
  type: principle
  source_chapter: 1.1.2
  source_quote: |
    类似的观察结果也出现在如减少参与人的选择集合或者降低他的信息质量之类变化的时候:这样的变化不会在确定的决策问题中
    对参与人有利,但在博弈中可能会产生对手行动上对自己有利的效果。
  summary: |
    内容: 与决策论相反的博弈论原理:自断退路、自减收益、自降信息质量,若被对手观察到,会改变对手的预期与最优反应,
    从而改善自己的均衡结局(图1—5→图1—6:参与人1主动把U的收益减2,对手因此改选R,参与人1反获利)。
    这是第3章"承诺价值"的种子。
    使用要点: 投资解读公司行为:回购锁定、长期合同、巨额专用产能投资、公开业绩指引,本质都是"自缚手脚换对手预期";
    判断此类公告价值时,看它是否可观察、不可逆——可逆的"自限"没有承诺效果。
  tags: [承诺, 自缚选择, 可信性]
  task_ids: [task-02]

  type: rule
  source_chapter: 1.1.3
  source_quote: |
    尽管合作会为每个参与人提供收益 1,但自利行为导致收益为 0 的无效率结果。……如果这里的博弈重复进行,
    其他结果可以成为均衡;这将在第4、5章和第9章中加以讨论。
  summary: |
    内容: 一次性囚徒困境中,一轮剔除严格优势即得唯一均衡(D,D)——自利导致无效率结果;
    作者明确给出边界:该结论依赖"博弈只进行一次",若重复进行,其他结果(合作)可以成为均衡。

    单次招标/一次性渠道博弈按背叛预测;长期重复关系才谈得上合作均衡(阈值条件见第5章,块P3)。

- id: pC1-11
  title: 二级价格拍卖中按真实估价投标是弱优势策略,且与信息结构无关
  type: rule
  source_chapter: 1.1.3
  source_quote: |
    对于每个参与人来说,以他的估价进行投标的策略(s_i = v_i)弱优于所有其他策略。……由于以估价出价是一种优势策略,
    所以投标者是否具有关于彼此估价的信息并不重要。
  summary: |
    内容: 二价(次高价成交)拍卖中"报真实估值"弱优于一切其他报价:报高有低价买进风险,报低有错失正剩余风险。
    由此可直接预言:估价最高的投标者中标,支付次高估价。
    关键推论(可执行):因为是优势策略,结论不依赖对手数量、对手估值信息——估值信息私有也不改变策略。
    使用要点: 投资参与资产处置/破产拍卖若为二价规则,直接按自估值报价,无需博弈猜测;反之若是一价规则,须向下压价(见第6章)。
  tags: [拍卖, 优势策略, 估值]
  task_ids: [task-05]

- id: pC1-12
  title: 团队平分产出+私人承担成本→"努力"是严格劣势策略(1/n道德风险)
  type: rule
  source_chapter: 1.1.3
  source_quote: |
    假设存在两个工人,i = 1, 2,每个人可以"工作"(s_i = 1)或"偷懒"(s_i = 0)。团队的总产出是 4(s_1 + s_2),
    并在两个工人中平均分配。……而"工作"对每个参与人来说都是一个严格劣势策略。
  summary: |
    内容: 可套用的结构判断:产出按份额平分、成本由个人私人承担时,努力的成本自担、收益被摊薄,
    "努力"成为严格劣势策略,均衡是全员偷懒——团队道德风险的博弈结构(数值例:总产出4(s1+s2)平分,努力成本3)。
    使用要点: 投资评估合资企业、合伙制、平台众包、大集团内部事业部时,检查激励结构是否落入此形态;
    判断管理层"激励是否足以对冲摊薄效应"(股权激励比例、考核颗粒度)是反推机制(task-09)的入口。
  tags: [道德风险, 团队激励, 机制反推]

- id: pC1-13
  title: 纳什均衡=一致预测;非均衡组合出现必有人"犯错"
  type: principle
  source_chapter: 1.2.1
  source_quote: |
    纳什均衡是关于博弈将会如何进行的"一致"预测,意思是,如果所有参与人预测特定纳什均衡会出现,那么没有参与人有动力
    采用与均衡不同的行动。因此纳什均衡(也只有纳什均衡)具有这一性质
  summary: |
    内容: 纳什均衡的独特性质:它是唯一"预测了就没人想推翻"的结果组合——每个参与人的策略都是对所预期对手策略的最优反应,
    且预期正确。任何非纳什组合一旦被普遍预期,至少有一方有动机偏离(要么预测错、要么没最优化)。
    使用要点: 投资中把"市场一致预期+无人有动机偏离"作为状态稳定性的判据;持仓逻辑若依赖"所有人明知偏离仍不偏离",
    需要额外的机制(协调、制度)来支撑,否则该状态不是均衡。
  tags: [纳什均衡, 一致预测, 稳定性]
  task_ids: [task-08]

- id: pC1-14
  title: 重复剔除后唯一幸存组合必是(唯一)纳什均衡;但均衡可赋权重于弱劣势策略
  type: rule
  source_chapter: 1.2.1
  source_quote: |
    当剔除一轮严格劣势策略导致唯一策略组合时,这一策略组合必然是一个纳什均衡(实际上是唯一的纳什均衡)。
    ……不过,纳什均衡可以对弱劣势策略赋予正概率。
  summary: |
    内容: 双向判断规则——(1)若重复严格优势(含单轮)剩唯一组合,它必是唯一纳什均衡;
    (2)反之,纳什均衡只会使用经得起重复剔除的策略,但例外:均衡可以对"弱劣势"策略赋予正概率
    (脚注7:单轮弱劣势剔除剩唯一组合也是纳什均衡,如二价拍卖按估价投标)。
    使用要点: 求解或检验行业均衡时:先用剔除法缩小范围;见到均衡中含弱劣势成分不要当作矛盾;
    含弱劣势策略的均衡对微扰不稳健(与pC1-15对照使用)。
  tags: [重复剔除, 纳什均衡, 弱劣势]
  task_ids: [task-08]

- id: pC1-15
  title: 严格均衡对收益微扰稳健;非退化混合策略不可能是严格均衡
  type: rule
  source_chapter: 1.2.1
  source_quote: |
    严格均衡必然是纯策略均衡。当收益函数受到轻微扰动时,由于严格不等式仍然得到满足,所以严格均衡也得到满足。
  summary: |
    内容: 判断规则——严格均衡(每人对其均衡策略是唯一最优反应,不等式严格)在收益函数受轻微扰动后仍是均衡,
    即对模型设定误差稳健;硬币配对类博弈说明非退化混合均衡必不严格(混合均衡中支撑集上各纯策略无差异)。
    适用条件: 严格均衡不一定存在(存在非退化混合均衡的博弈就没有)。
    使用要点: 投资结论稳健性排序:建立在严格均衡上的判断(利润差严格为正)优于建立在无差异/混合上的判断(临界相等);
    前者可承受参数估计误差,后者对误差零容忍。
  tags: [严格均衡, 稳健性, 微扰]
  task_ids: [task-08]

- id: pC1-16
  title: 均衡通过一致预测检验≠它是好预测
  type: maxim
  source_chapter: 1.2.1
  source_quote: |
    纳什均衡通过了一致预测检验并不意味着它们是好的预测,在一些局势中如果认为可以获得精确预测则显得过于轻率,……

    使用要点: 投资应用纪律:凡用博弈模型给出预测,必须补足策略式外的信息(历史行为记录、管理层背景、行业惯例);
    "模型说均衡是X"不能直接等同于"市场将实现X"。

- id: pC1-17
