  title: 公共项目供给的信息租金调整条件
  type: calculation
  source_chapter: 7.4.6

  summary: |

    output: 供给/不供给的决策规则
    missing_conditions: 原文在风险中性、拟线性偏好、独立类型、类型连续分布、预算平衡约束下推导;转写稿此处以同一均匀分布记号书写。

  type: rule
  source_chapter: 7.4.6
  source_quote: |
    罗布(Rob,1989)与梅勒斯和波斯尔思韦特(Mailath and Postlewaite,1990)证明了当 $I$ 趋于无穷时,如果 $c > \underline{\theta}$ 且 IR,IC,BB 得到满足,则公共项目被执行的概率趋于 0。

- id: pC5-03
  title: 最优拍卖按虚拟价值而非名义报价配置
  type: calculation
  source_chapter: 7.5.1
  source_quote: |
    令 $J_i(\theta_i) \equiv \theta_i - \frac{1 - P_i(\theta_i)}{p_i(\theta_i)}$ 代表买方 $i$ 的实际价值,令 $J_0(\theta_0) \equiv \theta_0$ 代表卖方的价值。……当且仅当 $J_i(\theta_i) = \max_{j \in \{0, \cdots, I\}} J_j(\theta_j)$ 时,$x_i(\theta) = 1$。
  summary: |
    内容:最优拍卖把商品配置给"虚拟价值"(实际价值)=名义价值减去信息租金项(逆Hazard率)最高的一方(卖方自己也是候选);卖方无私人信息,故 J_0=θ_0,不需为它支付显示激励。
    inputs: 类型分布 P_i、密度 p_i、估值 θ_i、卖方估值 θ_0
    formula: J_i(θ)=θ−(1−P_i(θ))/p_i(θ);x_i=1 ⟺ J_i 在{0,…,I}中最大
    units: 货币;x_i∈{0,1}
    output: 中标者与配置结果
    missing_conditions: 需类型分布外生已知;要求风险中性、拟线性、独立类型、分离条件 ∂²V_i/∂x_i∂θ_i≥0,且 J_i 非减(如单调似然率成立);若 J_i 在某区间递减,须按本章附录(ironing/拥挤)修正,见 Myerson(1981)。

- id: pC5-05
  title: 收入等价原理(相同配置+最低类型零剩余⇒相同收入)
  type: rule
  source_chapter: 7.5.1
  source_quote: |
    产生同样(配置)决策 $x_i(\cdot)$ 和使 $\underline{\theta}$ 型买方获得零剩余的所有拍卖给卖方带来相同的收入。
  summary: |
    内容:判断规则——两个拍卖若产生相同的配置规则 x_i(·) 且最低类型 θ̲ 买方剩余为零,则卖方期望收入相同。
    推论(原文):带相同保留价的一级价格拍卖与二级价格拍卖收入相同且都是最优的(Vickrey 1961;Myerson 1981;Riley and Samuelson 1981);两者的配置 x_i 与期望支付 T_i 相同,但事后支付 t_i 不同(一级只依赖自己出价、二级依赖次高价),实施机制存在灵活余地。
    使用要点:比较拍卖制度时,先比配置规则是否一致,再谈收入差异;配置规则相同则制度选择本身不改变卖方收入。

- id: pC5-07
  title: 非对称分布下拍卖歧视"平均更饥渴"的竞标人
  type: rule
  source_chapter: 7.5.1
  source_quote: |
    拍卖并不保证商品会出售给意愿收益最高的竞标人(Myerson,1981;McAfee and McMillan,1987b)……竞标人1"平均来说"比竞标人2更想获得该商品。此时拍卖将有利于竞标人2。
  summary: |
    内容:若竞标人1的逆Hazard率处处不小于竞标人2((1−P_1(θ))/p_1(θ) ≥ (1−P_2(θ))/p_2(θ) 对所有θ),则最优拍卖偏向竞标人2:存在 θ_1>θ_2 而 x_2(θ_1,θ_2)=1,却不存在反向情形。直觉:抑制"更想买"的类型可减少其信息租金。
    投资要点:并购/招标中,对标的依存度高、外部选择少("更饥渴")的竞标人会被机制歧视、须支付更高价格;预测成交对象先要刻画各竞买人的类型分布与外部选择,而非只比报价高低。

- id: pC5-09
  title: 双边交易最优规则(Myerson-Satterthwaite)与1/4阈值
  type: calculation
  source_chapter: 7.5.2
  source_quote: |
    当且仅当下式成立时 $v - \left( \frac{\mu}{1 + \mu} \right) \frac{1 - P_2(v)}{p_2(v)} \ge c + \left( \frac{\mu}{1 + \mu} \right) \frac{P_1(c)}{p_1(c)}$ (7.40) 交易发生。
  summary: |
    内容:预算平衡+IC+IR下,最优交易规则是买方估值扣除其虚拟租金项、卖方成本加上其虚拟租金项后比较;乘子 α=μ/(1+μ)∈[0,1) 由预算约束(7.37)取等号解出,α 越小越接近"v≥c 即成交"的理想规则。

    units: 货币;α∈[0,1)
    output: 交易发生/不发生的临界条件

- id: pC5-14
  title: 承诺必须包含"不重新谈判"才可信
  type: principle
  source_chapter: 7.6.4
  source_quote: |
    要使单期最优配置重复($T+1$)次成为动态(长期)最优配置,我们不仅要假设参与方在时期 0 可以签订一份法律上可以强制实施的长期合同,而且要求双方承诺(必须可置信)在将来不再修改初始契约,即使修改合同对双方都有利。
  summary: |
    内容:仅有法律可执行的长期合同不够——期初类型揭示后双方会重新谈判改进配置(Dewatripont 1989),故还须可置信地承诺"即使修改对双方都有利也不改约";否则动态最优机制不再是单期最优的重复,而由动态均衡决定:拟线性偏好下与第10章耐用品问题的科斯动态均衡相同(Hart-Tirole 1988;Laffont-Tirole 1990b)。
    投资要点:评估公司/政府的"长期协议"(长约、锁价、补贴承诺)时,关键不是合同能否强制执行,而是事后重新谈判的诱惑有多大;可预期的重新谈判会反过来扭曲期初行为。
