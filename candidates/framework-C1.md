- id: fC1-01
  title: 均衡建模预测法(馅饼王思维:预测对手靠建模找均衡,不靠外生信念)
  type: mental-model
  source_chapter: 引言
  source_quote: |
    馅饼王可以仅仅根据对其对手价格的一些给定的外生信念来最大化他的定价策略,不过看上去更令人满意的做法是根据对这个产业的一些知识来对这些价格作出预测。
  summary: |
    机制: 预测竞争对手行为时, 不把对手行动当作外生给定的信念, 而是建立一个描述每个竞争者行为(及其相互预期)的模型, 并寻找能构成该模型"均衡"的行为组合。
    原因: 对手也在基于"包含我方行动在内"的预测做决策, 所以预期是内生的, 需要交互模型而非单向猜测。
    适用条件: 竞争对手数量少、彼此行动相互影响的行业。
    操作要点: 先建对手行为模型(谁在什么变量上竞争、目标是什么), 再求均衡, 最后才谈"我该怎么行动"。
    这是全书方法论的总入口, 是 task-01(竞争格局判别)与 task-03(对手行为解读)的思考基座。
  tags: [均衡思维, 竞争分析]
  task_ids: [task-01, task-03]

- id: fC1-02
  title: 均衡概念二维定位器(按时序×信息两维度选解概念)
  type: framework
  source_chapter: 引言(全书路线图)
  source_quote: |
    当博弈同时是信息不完全和动态的时,贝叶斯纳什均衡的概念就显得太弱了,因为像纳什均衡在完全信息动态博弈中一样,它允许空洞的威胁存在。第8章介绍了将子博弈完美性的想法扩展到不完全信息博弈的求解思想。
  summary: |
    面对一个博弈/竞争情境, 按两个维度定位后选择解概念:
    steps: ①判断时序: 同时一次性行动(静态)还是有先后/重复(动态); ②判断信息: 收益结构共同知识(完全信息)还是对手类型未知(不完全信息); ③四象限选解概念: 静态+完全信息→纳什均衡(第1-2章); 动态+完全信息→子博弈完美(第3-5章); 静态+不完全信息→贝叶斯均衡(第6-7章); 动态+不完全信息→完美贝叶斯/序贯/颤抖手(按限制性从小到大递进, 第8-10章); ④动态完全信息若嫌子博弈完美仍太宽, 可再加严到马尔可夫均衡(第13章)。
    inputs: 对所研究行业互动的时序结构与信息结构的判断。
    outputs: 应采用的均衡概念及对应的可信性检验标准。
    missing_conditions: 相邻象限边界情形(如"弱动态""轻度不完全信息")如何取舍, 书中未给机械规则。
    作为总纲服务于全部 task, 对 task-01/03/08 尤为直接。
  tags: [均衡概念, 分析流程]
  task_ids: [task-01, task-03, task-08]

- id: fC1-03
  title: 博弈分析适用性判断(参与人少时才用博弈思维)
  type: mental-model
  source_chapter: 引言
  source_quote: |
    博弈论的观点在参与人数较少的时候更有用,因为那时参与人更有可能关心其对手。例如,在市场中厂商数目很少时,每个厂商的产量很可能会对市场价格产生很大的影响,因而,认为每个厂商将市场价格视为给定就不合理了。
  summary: |
    机制: 博弈论的价值来自"参与人关心对手、对手行动影响自己收益"。厂商数目少→单个厂商产量/定价能显著影响市场价格→不能视价格为给定→需要博弈模型; 参与人极多→价格接受→普通供需/完全竞争框架即可。
    适用条件: 分析前先判断行业中能实质影响价格的决策主体数量。
    操作要点: 遇到行业分析, 第一步数"有效参与人"(能影响价格的厂商), 再决定用博弈工具还是竞争均衡工具。
    这是 task-01 竞争模式判别的第一个分叉。
  tags: [适用条件, 竞争分析]
  task_ids: [task-01]

- id: fC1-08
  title: 重复剔除严格优势操作程序(IEDS)
  type: procedure
  source_chapter: 1.1.2(规范化见2.1.1)
  source_quote: |
    无论参与人1如何行动,R 向参与人2提供的收益总是严格比 M 所提供的要高。用规范的术语说,策略 M 是严格劣的。因此,"理性"的参与人2不应采用 M。
  summary: |
    仅凭"理性+收益是共同知识"可执行的预测程序。
    inputs: 策略式博弈(参与人、策略空间、收益矩阵/函数)。
    steps: ①在当前存活策略集上找出严格劣势策略(判定只需对照对手的各纯策略; 注意纯策略可能劣于某个混合策略, 图1-2/1-3); ②同时删除所有参与人的此类策略; ③在缩小后的集合上重复①②; ④直到无策略可删, 得存活集 S^∞。
    outputs: 存活集; 若唯一→该组合是唯一纳什均衡(且是严格均衡); 若非唯一→存活集仍是"任何纳什均衡必在其中"的必要缩小。
    missing_conditions: 弱劣势策略版本与剔除次序有关(第11章); 每多一轮迭代依赖多一层"我知道他知道…收益"假设(见fC1-27); 收益极端时实测行为可能背离解(图1-4)。

- id: fC1-09
  title: 纳什均衡一致性检验(逐人"有无利可图偏离"测试)
  type: framework
  source_chapter: 1.2.1
  source_quote: |
    纳什均衡是关于博弈将会如何进行的"一致"预测,意思是,如果所有参与人预测特定纳什均衡会出现,那么没有参与人有动力采用与均衡不同的行动。
  summary: |
    面对任何候选结果(自己预测的、公司公告将发生的、市场正在实现的), 用统一流程检验其稳定性:
    steps: ①固定其他参与人的选择; ②逐个参与人检查: 有没有能提高其收益的单方面偏离; ③混合策略情形只需检查纯策略偏离(期望收益线性); ④任一人有利可图→该结果不是均衡; 全员无利可图→纳什均衡。
    理论依据: 只有纳什均衡是"一致预测"——人人事前都预期它则无人想偏离; 非纳什结果意味着至少有人"犯了错"(预测错或优化错), 而预测错误需要分析者掌握比参与人更多的信息。
    用途: 检验市场共识/公司策略声明/预测结果能否自我维持, 是 task-01(价格/产量结构稳定性)与 task-08(共识脆弱性)的基础检验。
  tags: [纳什均衡, 稳定性检验]
  task_ids: [task-01, task-08]

- id: fC1-12
  title: 优势策略免除信念负担(机制设计视角)
  type: mental-model
  source_chapter: 1.1.3(例1.2)
  source_quote: |
    由于以估价出价是一种优势策略,所以投标者是否具有关于彼此估价的信息并不重要。因此,如果投标者知道他们自己的估价但不知道其他投标者的估价(参见第6章),每个投标者以估价出价仍然是一种优势策略。
  summary: |
    机制: 若某规则使"说真话/如实行动"成为每个参与人的(弱)优势策略, 则结果不依赖参与人对他人的信念, 也不依赖信息结构——二级价格拍卖中按估价出价即如此(逐情形验证: 出高/出低都在任何情形下不优于如实)。

- id: fC1-14
  title: 混合策略均衡的无差异条件求解法
  type: procedure
  source_chapter: 1.2.3-1.2.4(监察博弈、性别战等)
  source_quote: |
    为了使代理人在偷懒和工作之间无差异,必须有从偷懒中获得的收益(g)等于收入的期望损失(yw)。为了使委托人对监察和不监察无差异,监察成本(h)必须等于期望工资节省(xw)。因此,y = g/w 和 x = h/w
  summary: |

- id: fC1-28
  title: "非最优反应=严格劣势"等价性的失效诊断与相关信念修复
  type: troubleshooting
  source_chapter: 2.1.4
  source_quote: |
    严格劣势和不是最优反应之间的等价性在三人或更多参与人的博弈中失效。关键在于,由于混合策略假定了独立的混合,所以混合策略的集合是非凸的。不过,在可理性化中允许相关就重建了等价性:当且仅当一种策略不是对对手相关混合策略的最优反应时,该策略是严格劣势的。
  summary: |
