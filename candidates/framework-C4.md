# framework候选 块C4 (第6章+第7章前半)

- id: fC4-01
  title: 海萨尼转换——把"不知道对手是谁"变成"没看见自然怎么选"
  type: mental-model
  source_chapter: 6.1
  source_quote: |
    海萨尼(Harsanyi,1967—1968)首先提出了一种模拟和处理这类不完全信息博弈的方法,即引入一个虚拟参与人——"自然","自然"首先选择参与人1的类型(这里是他的成本)。在这个转换博弈中,参与人2关于参与人1成本的不完全信息就变成了关于"自然"的行动的不完美信息,从而这个转换博弈可以用标准的技术进行分析。
  summary: |
    机制内容: 遇到"我不知道你的收益/成本/意图"的不完全信息时, 不直接在不确定中推理, 而是引入虚拟参与人"自然"先按先验抽取每个人的类型, 原问题被改写成"是否看得见自然的行动"的不完美信息博弈, 于是纳什均衡等标准工具重新可用。
    适用条件: 私人信息能归纳为有限或可参数化的"类型"; 各方对类型分布有共同先验(作者自注: 自然代表天气等公共事件时共同先验更合理, 代表个人特征时较弱)。
    操作要点: (1)列出谁不知道谁的什么; (2)把未知定义成类型θi与先验分布p(·); (3)展开成自然先动的博弈树; (4)在转换后的博弈上求均衡。
    投资映射: 分析"对手(公司/庄家/监管)可能是什么类型"时, 先把未知明确为类型集+概率, 而不是含糊的"不确定"。
  tags: [不完全信息, 类型建模, 海萨尼转换, 建模方法]
  task_ids: [task-03, task-09]

- id: fC4-02
  title: "类型"的范围——私人信息全装进类型, 再做可解性简化
  type: mental-model
  source_chapter: 6.3
  source_quote: |
    在通常情况下,一个参与人的类型可能包括与其决策相关的任何私人信息(准确地说,是指不属于所有参与人共同知识的任何信息)。除了参与人的收益函数外,可能还包括他对其他参与人收益函数的判断,他对其他参与人对自身收益函数的判断的判断,等等。
  summary: |
    机制内容: "类型"是海萨尼框架的承载概念——凡不属于共同知识的私人信息(收益、成本、信念、对信念的信念)都可打包进类型θi; 博弈的外生结构(策略空间、先验、可能的类型集)则约定为共同知识。
    实用简化: 作者明确说, 类型太复杂模型就解不动, 实际运用通常假定"参与人关于对手的判断完全由他自己的收益函数决定", 即类型只保留收益相关维度。
    边界: 一维类型空间最易处理; 多维类型空间明显更难(脚注引Rochet等)。
    投资映射: 给公司/对手"分类"时, 先问哪些私人信息真正影响其最优行动(成本结构?现金流压力?考核任期?), 只保留影响决策的维度, 其余丢掉。
  tags: [类型建模, 不完全信息, 建模方法]
  task_ids: [task-03]

- id: fC4-03
  title: 贝叶斯均衡求解法——类型相依策略+对类型取期望的最优反应
  type: procedure
  source_chapter: 6.1/6.4/6.5(例6.2)
  source_quote: |
    求解贝叶斯均衡就是找到这样一组(x,y)使得x是低成本参与人1的最优策略;同时,给定参与人2关于参与人1的判断p1及参与人1的策略,y是参与人2的最优策略。
  summary: |
    求解不完全信息博弈的标准操作流程。
    inputs: 参与人集、各类型θi及先验p(·)(用条件分布p(θ−i|θi)算期望)、类型相依收益u_i(s,θ)。
    outputs: 一组类型相依策略s_i*(θ_i), 使每个类型在"对其他参与人类型取期望"意义下最优(即"展开博弈"的纳什均衡)。
    steps: (1)做海萨尼转换; (2)猜测/设定类型相依策略形式(单调、线性、cutoff等); (3)对每个类型写argmax一阶条件; (4)对不知情一方把对手策略按类型分布取期望再优化(例6.2古诺: q1=(2−q2H−q2L)/4); (5)联立方程解出策略; (6)验证(混合均衡另用无差异条件)。
    missing_conditions: 先验分布必须外生给定(现实中它恰是被推断的对象); 策略形式需猜测, 猜错需重设; 连续类型需可微性/存在性技术条件。
    注: 作者强调贝叶斯均衡只是"一致性检验", 不要求"判断的判断"进入定义。
  tags: [贝叶斯均衡, 求解方法, 不完全信息]
  task_ids: [task-03, task-05]

- id: fC4-04
  title: "一刀切"(cutoff)与单调策略结构
  type: mental-model
  source_chapter: 6.2/6.6.1
  source_quote: |
    但在贝叶斯均衡中这种情况就不会发生,因为正如我们所看到的,在任何贝叶斯均衡中,每一参与人都必须采取"一刀切"策略(cutoff rule):对某些c',当且仅当ci≤c'时提供。也就是说,在贝叶斯均衡中,如果给定成本类型的参与人i提供,则所有成本更低的参与人i必然也会提供。
  summary: |
    机制内容: 类型一维且偏好满足常规排序时, 均衡策略几乎总是类型的单调函数——成本低于临界值才供给、估值高于临界值才出价。作者称之为"单调性"特征, 指出它"在经济分析中经常用到", 并贯穿6.3消耗战、6.4双边拍卖、6.5一级拍卖与第7章机制设计。
    为什么成立: 类型之间只剩排序差异, 若某类型愿意做, 更极端的类型必然更愿意(6.3/6.4用两组最优性不等式相减给出严格论证)。
    适用条件: 单交叉/分离条件成立(第7章A1)、类型一维。
    投资映射: 观察企业的类型依存行为(扩产、降价、回购)时, 先猜"cutoff+单调"形式再验证, 可把"各种可能行为"压缩成一两个临界参数。
  tags: [单调性, cutoff, 贝叶斯均衡, 单交叉]
  task_ids: [task-03, task-05]

  type: procedure
  source_chapter: 6.5(例6.3)
  source_quote: |
    现在,我们令P1=P2=P,求解对称均衡。去掉方程(6.3)的下标,令θ=Φ(s),并注意到Φ'=1/s',我们得到s'(θ)=θp(θ)/(1−P(θ))。
  summary: |
    inputs: 双方同时选"坚持时长"s_i; 赢者得奖金θ_i(私人信息, 分布P), 双方都支付自己选的时长成本(似二级拍卖但败者也要付)。
    outputs: 对称严格递增连续均衡策略s(θ)=∫₀^θ xp(x)/(1−P(x))dx, 边界s(0)=0。

  type: procedure
  source_chapter: 6.5(例6.3/例6.5)
  source_quote: |
    首先,如果策略不是严格递增的,那么在某些s>0处必然存在一个"原子",即使得Prob(si(θi)=s)>0。
  summary: |
    验证均衡策略"严格递增+连续"的通用检查流程, 在消耗战(例6.3)与一级价格拍卖(例6.5)中同构出现, 作者说拍卖一题"步骤与例6.3、例6.4中单调性的证明相同"。
    inputs: 候选均衡策略s_i(·)、对手策略分布、收益结构(出价高者赢/坚持久者赢)。

  summary: |
    求解买卖双方各有私人估价、成交价取双方报价均值(k=1/2)的议价博弈的线性贝叶斯均衡。

- id: fC4-10
  title: 事前优势vs事中优势——剔除视角的选择
  type: mental-model
  source_chapter: 6.6.1
  source_quote: |
    有意思的是,严格重复剔除优势的"事前"解释至少是和"事中"解释同样强的概念,而且在某些博弈中,"事前"解释可以得出更强的预测。
  summary: |
    机制内容: 同一个"剔除劣策略"在两种视角下强度不同。事中解释: 每个类型θ_i像独立个体, 在知道类型后各自预测对手; 事前解释: 单一参与人在知道类型之前统一预测对手, 所有类型共享同一套对手策略预期。事前劣势策略集合⊇事中劣势策略集合, 故事前剔除能排除更多非均衡行为(如公共产品博弈中的非一刀切策略, 事中剔除数轮后仍有区间解, 事前剔除直接逼出cutoff结构)。
    适用条件: 优势方法允许各方对第三方预测不一致, 两种解释才有差别; 用纳什均衡(一致性预测)则无差别。
    操作要点: 先试事中逐轮剔除; 若剩多个解, 换事前视角(把类型相依策略当整体)常可唯一化(图6—5b: DU劣于UD→L→唯一解(UU,L))。
    投资映射: 评估"同一家公司不同处境下的行为"时, 把全部处境的行为当成同一个决策主体的整体计划来检验一致性。
  tags: [重复剔除, 优势策略, 不完全信息, 精炼]

- id: fC4-11
  title: 逐轮剔除优势的临界值迭代法
  type: procedure
  source_chapter: 6.6.2
  source_quote: |
    在阶段2k+1(k=0,1,2,…),"提供"是成本高于c^{2k+1}≡1−P(c^{2k})的参与人的严格劣势策略。在阶段2k(k=1,2,⋯),"不提供"是成本低于c^{2k}≡1−P(c^{2k−1})的参与人的严格劣势策略。
  summary: |
    用重复剔除严格优势策略(而非均衡假设)求解不完全信息博弈的流程。
    inputs: 类型分布P、收益结构(公共产品供给例: 提供成本ci、私人收益1)。
    outputs: 两个交错收敛的临界序列{c^{2k+1}}↓与{c^{2k}}↑; 若极限重合于c*(即c*=1−P(1−P(c*))有唯一解), 博弈被(事中)重复剔除可解, 预测唯一。
    steps: (1)第一轮: 成本>1者"提供"为劣; (2)第二轮: 成本<1−P(1)者"不提供"为劣; (3)交替迭代c^{2k+1}=1−P(c^{2k})、c^{2k}=1−P(c^{2k−1}); (4)证两序列单调有界→收敛; (5)检查两极限是否重合。
    missing_conditions: 极限重合需要均衡唯一性条件成立; 不重合时剔除法只给出区间而非唯一点(此时可改用事前剔除, 见fC4-10)。
    投资映射: 不需要假设"人人理性预期", 只用"绝不选劣策略"逐层收缩对手可能行为的区间。
  tags: [重复剔除, 公共产品, 求解方法, 不完全信息]

- id: fC4-12
  title: 混合策略的贝叶斯纯化——"抛硬币"其实是"不知道对手类型"
  type: troubleshooting
  source_chapter: 6.7
  source_quote: |
    正如海萨尼(Harsanyi,1973)指出的,完全信息博弈的混合策略均衡可以解释为不完全信息"微扰动博弈"纯策略均衡的极限。确实,我们在贝叶斯博弈中已经注意到,一旦参与人的类型相依策略确定,他就会设想是面对对手的混合策略并相机行事。(这里造成不确定性的原因是类型分布而非抛硬币。)
