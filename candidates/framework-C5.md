- id: fC5-01
  title: 大群体公共品供给失效的"关键人物概率归零"机制
  type: mental-model
  source_chapter: 7.4.4
  source_quote: |
    这一结果从直观上看是非常简单的。如果代理人很多,则代理人成为决策中心人物(即 $\hat{\theta}_i$ 的改变会导致 $x$ 的改变)的概率就非常小,如果代理人是连续分布的,则这一概率就为 0。这样,代理人 $i$ 的目标就简化为使他获得的期望转移支付最大,即使他对公共产品的期望贡献最小化。
  summary: |
    思考结构: 判断集体行动/公共品问题能否由自愿机制解决时, 先问"单个参与者改变结果的概率(关键人物概率)有多大"。
    机制: 人数越多, 单个报告改变供给决策x的概率越小(连续分布时为0)→个体只关心最大化自己的期望转移支付(即最小化分摊贡献)→贡献被最低类型的个人理性约束封顶在θ̲→期望收入入不敷出, 违反预算平衡。
    结论: 代理人趋于无穷多时, 有效公共项目被执行的概率趋于0(Rob 1989; Mailath-Postlewaite 1990), 即使"每个人受益都超过人均成本"、交易有效概率接近1。
    出路: 需要外部强制或补贴, 单位资本补贴≈c-θ̲。
    投资映射: "人人受益但无人愿单独买单"的环节(股东监督、行业自律、基础研发、公共数据)在大群体中必然供给不足; 判断谁能收钱=找到有强制力或能排除搭便车者的一方。
  tags: [公共品, 集体行动, 机制设计, 搭便车]
  task_ids: [task-09]

- id: fC5-02
  title: 最优拍卖的虚拟价值求解程序
  type: procedure
  source_chapter: 7.5.1
  source_quote: |
    由显示原理,卖方可以只考虑直接显示机制 $\{x(\cdot), t(\cdot)\}$。……在最优机制下,$U_i(\underline{\theta}) = 0$,因为此时卖方没必要让买方享有(信息)租金。
  summary: |
    inputs: 卖方自用价值θ0(共同知识)、各买方类型独立分布P_i(严格正密度)、拟线性偏好且满足分离条件(边际效用随θ递增)。
    steps: 1) 由显示原理限定于直接显示机制; 2) 把期望收入改写为"总期望剩余-买方信息租金之和"(式7.28); 3) 用包络定理把租金写成U_i(θ_i)=U_i(θ̲)+∫X_i dθ(式7.30); 4) 令最低类型零租金U_i(θ̲)=0; 5) 分部积分得到虚拟价值J_i=θ_i-(1-P_i)/p_i(式7.31-7.32), 目标变为最大化ΣJ_i·x_i加卖方项; 6) 把商品配给虚拟价值最高者(对称分布时等价于价高者得+保留价θ*, 由θ*-(1-P)/p=θ0定义且θ*>θ0, 部分交易利得被主动放弃); 7) 校验IC剩余条件X_i(·)非减——若J_i非减(如单调似然率成立)则自动满足, 否则进入附录拥挤算法(fC5-14); 8) 由式7.35反解期望转移支付T_i, 事后支付t_i的实行方式(一级价付出价/二级价付次高价)有自由度, 不改变收入。
    outputs: 最优配置规则、对称情形保留价、最优期望转移支付。
    missing_conditions: 需假定J_i非减, 否则需ironing; 风险回避买方时程序失效(见fC5-09); 类型独立假设(相关时见fC5-08)。
  tags: [拍卖, 机制设计, 信息租金, 虚拟价值]
  task_ids: [task-05, task-09]

- id: fC5-03
  title: 收入等价原理的推理路径
  type: framework
  source_chapter: 7.5.1
  source_quote: |
    其次,产生同样(配置)决策 $x_i(\cdot)$ 和使 $\underline{\theta}$ 型买方获得零剩余的所有拍卖给卖方带来相同的收入。我们稍后将解释这一收入等价原理的含义。
  summary: |
    推理结构: 收入=期望总剩余-Σ信息租金; 而由包络公式, 租金只由配置规则X_i(·)与最低类型租金U_i(θ̲)决定, 与支付规则的具体形式无关。
    因此: 只要两种拍卖①配置决策x_i(·)相同②给最低类型零剩余, 收入必然相同——一级价格与二级价格拍卖(带相同保留价)收入相同且(对称、独立私人价值下)都是最优, 尽管中标者支付路径不同(付自己的出价 vs 付次高价)。
    适用条件: 独立私人价值、风险中性、拟线性偏好; 离散类型时不成立(7.1节两类型例中一价/二价拍卖都非最优)。
    投资映射: 比较招标/资产处置/定增等机制时, 先看配置规则与底线租金是否相同; 相同则"支付形式之争"不改变卖方所得, 分析焦点应放在配置规则本身。
  tags: [拍卖, 收入等价, 信息租金]

- id: fC5-04
  title: 非对称分布下"价高者得"失效的诊断
  type: troubleshooting
  source_chapter: 7.5.1
  source_quote: |
    关于非对称分布的例子,拍卖并不保证商品会出售给意愿收益最高的竞标人……也就是说,竞标人1"平均来说"比竞标人2更想获得该商品。此时拍卖将有利于竞标人2。
  summary: |
    症状: 拍卖/竞标结果没有落在名义估值最高者手中, "强势"买方反而拿不到标的或被迫付出更多。
    判断条件: 比较的对象应是虚拟价值J_i=θ_i-(1-P_i)/p_i而非名义估值θ_i; 若对同一θ有(1-P_1)/p_1≥(1-P_2)/p_2(买方1的估值分布"平均更高"), 最优机制会系统性偏向买方2——存在θ1>θ2而x_2=1, 却不存在反向情形。
    操作: 用各竞标人分布反推虚拟价值并据此排序、设门槛; "歧视"强买方是卖方榨取其信息租金的手段。
    验证: 检查所得配置规则是否满足X_i非减(激励相容)。
    missing_conditions: 需估计各竞标人估值分布P_i——投资场景中只能近似。
  tags: [拍卖, 虚拟价值, 非对称信息]
  task_ids: [task-05]

- id: fC5-05
  title: 迈尔森-萨特思韦特最优交易规则求解程序
  type: procedure
  source_chapter: 7.5.2
  source_quote: |
    迈尔森和萨特思韦特将方程(7.40)用于分析 $[0, 1]$ 上均匀分布的情形……解得 $\dfrac{\alpha}{1+\alpha} = \dfrac{1}{4}$。在最优交易规则下,当且仅当买方的价值至少比卖方的成本高 $\dfrac{1}{4}$ 时,交易才会发生。
  summary: |
    inputs: 卖方成本c~P_1、买方价值v~P_2(独立、严格正密度), 双方风险中性, 预算平衡(无第三方补贴)。
    steps: 1) 由IR+IC+BB推出必要不等式E{(J_2(v)-J_1(c))x(c,v)}≥0(式7.37), 其中J_1(c)=c+P_1(c)/p_1(c), J_2(v)=v-(1-P_2(v))/p_2(v); 2) 写拉格朗日函数(乘子μ, 式7.38); 3) 一阶条件给出交易规则(式7.40): v-α(1-P_2)/p_2 ≥ c+αP_1/p_1, α=μ/(1+μ); 4) 令约束式7.37取等(当c̄>v̲时必然取等)解出α——均匀分布时α/(1+α)=1/4; 5) 校验X_1(·)非增、X_2(·)非减: 单调似然率成立时自动满足, 规则即最优。
    outputs: 信息不对称+预算平衡下交易利得最大的交易规则(均匀分布: v-c≥1/4才成交, 互利交易被无谓放弃; 该规则恰由第6章Chatterjee-Samuelson线性双边拍卖均衡实现)。
    missing_conditions: "无私第三方"目标函数的解释并不令人满意(作者自承); 要求双方时间偏好相同; 对"一般"分布该规则未必可由双边拍卖实施(Satterthwaite-Williams 1989)。
  tags: [双边交易, 议价, 机制设计]
  task_ids: [task-06]

- id: fC5-06
  title: 承诺时点判别框架(事前承诺 vs 事中参与约束)
  type: framework
  source_chapter: 7.5.2
  source_quote: |
    如果参与方可以承诺使用该机制,则他们就会执行该机制,因为"事中"IR 约束通常会导致无效率,而在没有"事中"IR 约束时,我们可以用 AGV 机制来达到事后有效结果(即当 $v \ge c$ 时,$x = 1$;当 $v < c$ 时,$x = 0$。)
  summary: |
    判断交易/协商能否有效率的决策框架, 关键变量是"个人理性约束在哪个时点生效":
    ①事前承诺(获知私人信息之前签约, 用退出罚金等锁定)→事中IR可丢弃→AGV机制实现事后有效(v≥c即交易);
    ②只有事中IR(获知信息后才决定是否接受机制)→fC5-05的无效率不可避免, 互利交易被放弃;
    ③承诺手段本身有限(如法律上工人不能承诺辞职罚款), 需逐一检验可行性;
    ④双方时间偏好不同时结论改变——耐心方可通过向不耐烦方放贷改变可行效用集。
    作者同时提示该模型的另一解释: 非合作协商博弈均衡效用的特征描述(见fC5-07)。
    投资映射: 并购/谈判中判断"先签框架协议+分手费"式的事前承诺能否消除信息不对称导致的交易破裂。
  tags: [承诺, 议价, 个人理性约束]

- id: fC5-07
  title: 机制设计作为议价结果上界的推理框架
  type: framework
  source_chapter: 7.5.2
  source_quote: |
    一个已知的结论是,只要交易双方具有相同的时间偏好,协商过程的任何(贝叶斯)均衡都能够获得一个配置,该配置能被满足条件 IC 和 IR 的机制设计所解释。这一结论实际上是显示原理的直接应用……计算满足 IR,IC 和 BB 的机制所能达到的最大期望社会剩余可以看做是求解无仲裁双边议价博弈(结果)的有效上界的过程。
  summary: |
    思考结构: 要给一场无法完全建模的谈判"定上限"时, 不必解谈判博弈本身, 只需解一个松弛的机制设计问题。
    推理路径: ①把任何议价均衡结果(成交时刻τ(c,v)、成交价z(c,v))映射为机制——交易概率x=e^{-rτ}, 转移w=e^{-rτ}z, 即"达成协议所需的时间(τ>0)相当于交易不发生的概率(x<1)"; ②该机制自动满足IR(可拒绝交易得零效用)、IC(均衡定义)、BB(无第三方); ③于是"满足IR/IC/BB的最大期望剩余"就是任何无中介议价结果的上界(具体求解程序=fC5-05)。
    适用条件: 双方时间偏好相同; τ、z为确定值(随机情形可类推)。
    投资映射: 估算并购、债务重组谈判的可行份额区间——上界给出"最好情况", 实际均衡因拖延与信息问题只会更低。
  tags: [议价, 显示原理, 上界推理]
  task_ids: [task-06]

- id: fC5-08
  title: 类型相关时的信息攫取(通吃机制与得分规则)
  type: mental-model
  source_chapter: 7.6.1
  source_quote: |
    如果所有报告向量完全相同,委托人实施对应于报告类型向量的最优充分信息配置(可能满足也可能不满足 IR 约束,视情况而定);如果报告向量不完全相同,则委托人"通吃":对所有的 $i$,$t_i = -\infty$。
  summary: |
    思考结构: 类型相互独立时激励成本不可避免(fC5-02); 但类型相关时, 各代理人的报告可以相互"对账", 委托人能近乎免费地获取信息。
    机制: 完全相关→"通吃"机制(报告一致才实施最优配置, 不一致则天价罚金)使说真话成为唯一不被惩罚的选择; 不完全相关→把转移支付设为他人报告的条件似然(适当得分规则), 并乘以大常数K以抵消谎报对配置收益的影响; 可行性由满秩条件决定(两代理两类型: q11·q22≠q21·q12), 类型相关性越弱所需罚金越大。
    边界: 作者自承结论极端——巨额或然罚金"夸大了风险中性的可信度", 且通吃机制存在合谋谎报的其他均衡。
    投资映射: 判断审计/监管/平台能否用多源数据交叉验证识别造假; 数据源之间"满秩"(独立到可互相检验)的程度决定造假可被惩罚的强度。
  tags: [相关类型, 机制设计, 信息攫取]

- id: fC5-11
  title: 动态机制设计的承诺三分法
  type: framework
  source_chapter: 7.6.4
  source_quote: |
    要使单期最优配置重复($T+1$)次成为动态(长期)最优配置,我们不仅要假设参与方在时期 0 可以签订一份法律上可以强制实施的长期合同,而且要求双方承诺(必须可置信)在将来不再修改初始契约,即使修改合同对双方都有利。
  summary: |
    分析重复的委托-代理/监管/长期合同问题的三层框架, 决定性变量是承诺的完全程度:
    ①完全承诺→动态最优=单期最优机制重复T+1次(证明: 把多期IR/IC按1/(1+δ+…+δ^T)加权化成单期约束、构造随机静态机制得出矛盾——一个可复用的"动态约束平均化"推理);
    ②有长期合同但允许再谈判→类型暴露后双方必然重签契约, 动态均衡呈科斯动态(Hart-Tirole、Laffont-Tirole证明与第10章耐用品的科斯均衡同构);
    ③无承诺(只能一期一期签)→棘轮效应(fC5-12)。
    关键辨析: "法律上可执行的长期合同"≠承诺; 还需"即使对双方有利也不修改"的可信约束。
    投资映射: 评估长期协议/监管承诺可信度时先问属于哪一层; 第②层意味着初期条款再好, 之后也会向"科斯式"重新定价漂移(与task-07的降价预期同构)。
  tags: [动态机制设计, 承诺, 再谈判]

- id: fC5-12
  title: 棘轮效应(无承诺重复机制下的类型混同)
  type: mental-model
  source_chapter: 7.6.4
  source_quote: |

    思考结构: 序贯均衡的一致性不仅是技术条件, 其经济含义是"所有参与人对同一偏离事件共享同一套相对概率解释"——图8-5中参与人2、3对参与人1偏离的判断必须同源, 否则该评估不一致, 均衡被排除。
    机制: 各自独立构造的信念即使各自满足贝叶斯更新与结构一致性, 也可能不来自同一颤抖序列→不一致→加入共同信念要求后均衡集严格缩小(图8-5中没有一致评估支持参与人1选A)。
    作者立场: 这是均衡精神的自然要求, 但"不敢确信令人信服"——现实中不同观察者完全可能用不同理论解释同一异常事件。
    投资映射: 市场对同一异常(高管减持、业绩预亏)的解读若一致→行为趋同、共识自我强化; 解读分裂→行为分歧。均衡分析默认"一致解读", 用于现实检验时要意识到这一强加假设。

    对于一般性的收益而言序贯均衡评估集是各维流形的并集;这些流形的维度与在规定路径外策略和信念时可行的"自由度"的大小有关。……由于参与人2在 $\ell$ 与 $r$ 之间随机选择时是无差异的,所以在明确说明信念时就必须丧失一个自由度,以得到明确说明混合策略时的 1 个自由度。
