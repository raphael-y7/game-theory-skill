# 信息结构敏感性与共同知识（路由能力卡）

## R — 原文

> "如果信号是公共观察的,则它们的作用仅是凸化纳什均衡收益集合。如果信号是私人观察,但仍然相关,则它们也允许不完美相关均衡,可能具有纳什均衡凸壳之外的收益,例如图2—4中的(3⅓,3⅓)。"(2.2)

> "唯一的纳什均衡是:即使所有的脸都是脏的,也没有任何参与人脸红。…在这种信息结构下,不再存在所有人的脸都是脏的但没有人脸红的纳什均衡。"(14.3.1)

> "即使在这个状态下,两人在均衡中还是选择 B:尽管两人都知道收益如图 14—2a 所示,但这不是共同知识。…对任何 ε>0……都不存在一个参与人采取(A, A)的均衡,即使(A, A)在收益确定就是图 14—4a 所示收益的情况下是一个严格均衡。"(14.4.1)

## I — 自述

这张卡评估**信息结构本身**对均衡的冲击：一次财报披露、一条传闻的多级转发、披露规则的改动，会不会翻转均衡？"人人都知道"与"人人都知道人人都知道"差在哪？

第一把尺子：**公共信号 vs 私人相关信号**。公共可观察的随机变量（宏观数据、官方喊话、太阳黑子）只能在既有纳什均衡收益的凸壳上做凸化——帮市场在旧均衡间协调，不创造新结果；市场情绪的"自我实现"正是公共信号的凸化协调。私人但相关的信号（各家收到的独家但同源的信息）才能实现凸壳之外的新均衡——能改变联合收益上限的是结构性私人信息。

第二把尺子：**知识的层级**。脏脸谜题：圣人宣布"至少有一张脏脸"——一句人人已知的话——把该事实升格为**共同知识**后，归纳链条启动，均衡完全翻转。只检查"每个人是否知道"而不检查"每个人知道每个人知道…"的分析会得出完全错误的预测；"宣布众所周知的事实"（亏损确认、行业共识数据）引发市场剧烈反应，正是层级升格的效应。

第三把尺子：**近似共同知识与信道噪声**。电子邮件博弈：协调行动 (A,A) 是严格均衡，但只要信息传递任何一环有 ε>0 的丢失概率（无论多小、已确认多少轮），唯一均衡是所有状态下都选 B——归纳沿消息轮数展开，每层条件概率都让 B 逐层占优。**多级转达救不了信道噪声**；传闻链、层层传达的指引、多级确认的合同，协调都可能在"确定性与近似确定性"之间崩溃。

第四把尺子：**共同先验下的信息变现极限**。无交易/无泡沫定理——共同先验+理性+有限交易者时，知情者的信息优势无法变现（对手报价已内生化信息），资产价格恒等于分红现值。反向信号：市场上信息优势方持续盈利、价格长期偏离基本面 → 共同先验/有限交易者假设失效（异质先验、噪声交易者、交叠世代存在）。

## A1 — 应用示例

**例1：脏脸与圣人（worked_example, 14.3.1, c89）**
输入：三人脏脸博弈，圣人宣布"至少有一张脏脸"。
执行：公告前——无人脸红是纳什均衡（层级缺失，归纳无法启动）；公告后——该事实成为共同知识，第1期无人脸红推出"不止一张"，逐期归纳至按脏脸数量全员脸红。
结论：一句"废话"改变均衡——信息披露的信息量不在内容新旧，在层级升格。

**例2：电子邮件博弈（worked_example, 14.4.1, c94）**
输入：协调收益 (A,A)=(8,8) 严格均衡；信息从 A 到 B 再确认回 A，每轮丢失概率 ε。
执行：状态 n（已确认 n−1 轮）下归纳——每层"对方可能不知道"的条件概率都超过 1/2 → B 逐层占优 → 对任何 ε>0 无 (A,A) 均衡。
结论：任一环有噪声，严格均衡也崩溃；收益差巨大（8 vs −10）反而更不敢动——评估多级信息传递的协调可靠性时不看"已确认几轮"，看信道结构。

**例3：无交易定理的边界诊断（worked_example, 14.3.3, c92）**
输入：风险中性市场、共同先验、知情交易者。
执行：知情买入本身泄露"增值"信号 → 对手报价内生化 → 无套利抹平信息租金 → 不交易不劣于交易（无套利结果，非严格优于）；跨期价格=分红现值，无泡沫。
结论：发现知情者持续获利/持续泡沫 → 共同先验或有限交易者假设失效——用定理的失效反推市场结构。

## A2 — 未来触发

**情境**：评估一次披露/公告/传闻对市场均衡的冲击方向；分析多级转发信息链的协调可靠性；判断"人人都知道"的公开信息为何突然引发剧烈反应；识别泡沫/持续信息优势背后的市场结构异常；评估披露规则改动的均衡效应。

**语言信号**（中英）：共同知识、信息结构、公开信息、传闻、多级转发、披露规则、无交易、泡沫、common knowledge, information structure, disclosure, no-trade theorem, higher-order beliefs。

**与相邻能力的区分**：vs 信号解读（U8）——那张解读单一行动的信号含义；本卡评估信息结构整体（公共/私人、层级、渠道、时点）对均衡集的冲击。vs 多重均衡卡（U14）——本卡的邮件博弈是信息结构脆弱性；那张的太阳黑子是协调装置（互见）。vs 监督结构卡（U4）——那张管重复博弈内的监控质量；本卡管均衡层面对信息结构的敏感性。

## E — 执行

**输入契约**：信息事件的完整传播图（谁、何时、通过什么渠道、谁可见）；既有均衡结构；信息链条的丢失/噪声概率（可估则估）。

**步骤**：
1. **画信息结构图**：每个参与人知道什么、知道谁知道什么（至少两层）；信号是公共还是私人相关。**三层表模板**：第一层"谁知道什么"（各方私人信息与已观察信号）、第二层"谁知道谁知道"（对各方的知情状态的高阶判断）、第三层"是否有公共见证"（有无可公共观察的宣布/记录，决定共同知识能否成立）。**行业披露链示例**：公司→交易所→媒体→投资者，每跳标注可见性与丢失概率（公司→交易所 ε₁、交易所→媒体 ε₂、媒体→投资者 ε₃），全链丢失率≈1−(1−ε₁)(1−ε₂)(1−ε₃)。完成标准：结构图+分类。
2. **判断信号作用**：公共 → 只协调（凸化），不改变均衡集；私人相关 → 可能创造新均衡。完成标准：作用归类。
3. **查层级升格**：事件是否把某个人人已知的观察升格为共同知识（公开宣布、集体见证）？是 → 预期行为翻转风险。完成标准：升格判定。
4. **查信道噪声**：信息链是否多级传递、任一环有无丢失可能？有 → 按"近似共同知识"评估协调可靠性，勿按确定性逻辑。**ε 校准法**：用历史信息链的实际丢失/延迟频率估 ε 量级（多级转发延迟率、数据修正频率、公告遗漏率）；无数据时按"至少一级存在正丢失概率"做最不利评估（ε>0 即按崩溃情景处理）。完成标准：信道评估。
5. **反推市场结构**（若适用）：信息优势持续变现/持续泡沫 → 标记共同先验假设失效。口径："持续"的观察窗口至少覆盖一个完整业绩周期（如 4 个季度），短于该窗口的盈利不构成"持续"证据。完成标准：结构异常清单。
6. **输出**。完成标准：(a) 信息结构分类与冲击方向；(b) 层级/信道风险评估；(c) 均衡翻转情景；(d) 稳健度（ε 敏感性声明）。

**判停点**：传播图无法还原时按最不利结构（存在噪声环）评估；层级超过三层且无公共见证时输出"协调可靠性存疑"而非点判断。

## B — 边界

1. **层级分析必须走到底**：只到"大家都知道"第一层的信息分析常错；归纳链条的每一层都可能翻结论。
2. **ε 的普遍性**：任何正的丢失概率都瓦解严格均衡——"几乎确定"≠确定；但真实市场有其他锚定机制（价格、公开成交），勿机械套用崩溃结论。
3. **无交易/无泡沫定理前提苛刻**：共同先验+理性+有限交易者；现实中异质先验、噪声交易者、交叠世代普遍存在——定理更适合作为"失效检测器"而非预测。
4. **信号机制不删除旧均衡**：增加信号不消除原有均衡（可共同忽略）——"新信息到来"未必改变行为，除非层级/收益改变。
5. **信息关联的灵活性代价**：可观察历史把行为人锁进单一声誉（另见声誉卡）；信息披露越多不必然越好。
6. **作者盲点**：共同先验假设被作者自注为"个人特征情形下较弱"；有限记忆与注意力成本不建模；社交媒体时代的传播结构（病毒式、算法推荐）超出邮件博弈的线性链条。
