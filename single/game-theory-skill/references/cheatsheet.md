# 决策规则速查 — 博弈论(Game Theory)

| 能力 | 一句话规则 |
|---|---|
| 合谋可持续性与价格战分析 | 合作可持续 ⟺ 未来惩罚损失的贴现和 > 当期背离利得——用δ阈值、惩罚深度与期限结构三件事判断 |
| 信号解读与动态不完全信息分析 | 信号可信 ⟺ 信号成本随类型系统性不同(单交叉)——找成本差; 解读行动=求PBE四件套(类型/策略/信念/反应) |
| 承诺与威慑可信性分析 | 威胁可信 ⟺ 兑现条件真出现时执行它仍是执行者自身最优(子博弈完美); 承诺要有价值必须可观察、不可逆、真的改变对手最优反应 |
| 竞争格局判别与比较静态分析 | 先还原底层博弈规则(竞争变量×时序×信息)再选模型; 反应曲线交点给均衡位置, 交叉偏导符号给比较静态方向 |
| 时机竞争：消耗战、抢先与退出分析 | 用L/F/B三曲线分类——环境变好→ε领先即零消耗全胜; 环境变差→大企业先退小企业留守; 无主租金→被竞赛完全耗散 |
| 品牌、平台与长期关系资产评估 | 声誉价值 = 未来关系租金流 vs 欺骗一次的短期利得; 短期方能否观察长期方全部历史并先行行动决定合作可行集 |
| 声誉与强硬表态分析 | 威慑可持续 ⟺ 对手给承诺类型的先验p⁰超过[b/(b+1)]^k; 期限越长阈值几何衰减, 越微小的强硬先验越够用——但无论如何都会说的话零信息 |
| 行业博弈建模与预测基础 | 先数有效参与人、把局势写成扩展式, 按时序×信息两维选均衡概念; 只凭大家都不笨推不出唯一点——输出区间+稳健度 |
| 监督结构与合作纪律 | 偏离若不可统计归因就不可惩罚——先查公共信号能否区分谁在背离、是背离还是冲击, 再谈δ阈值 |
| 拍卖与竞价分析 | 一价拍卖往下压(赢率损失与省下的钱相抵), 二价按真实估价报(优势策略); 保留价必然高于卖方自用价值, 流拍可能是设计而非不值钱 |
| 议价、交易破裂与耐用品定价 | 份额由相对耐心决定(可算); 双边私人信息+预算平衡下部分互利交易必然破裂(v-c≥1/4); 无承诺+理性前瞻⇒定价力量被科斯逻辑侵蚀 |
| 机制反推与筛选定价 | 制度是设计者最优化的解——翻译成(x,t,θ)→显示原理化简→识别IR/IC紧约束→信息租金决定扭曲结构(高端无扭曲/低端缩量) |
| 说真话机制与集体行动 | 人多时方向相反——私人品市场近似有效(谎报无利可图), 公共品集体行动必然供给不足(关键人物概率归零); 说真话靠关键人物付费或类型相关交叉验证 |
| 多重均衡与共识稳定性 | 多重均衡下预测=区间而非点位, 实现靠协调机制(聚点/公共信号/惯例); 参数跨临界值均衡可无中生有, 信念解读分裂则共识瓦解 |
| 信息结构敏感性与共同知识 | 公共信号只在既有均衡间协调, 私人相关信号才创造新均衡; 近似共同知识与确定共同知识的均衡集不同——多级确认救不了信道噪声 |
| 马尔可夫状态变量 | 状态变量须同时满足概括历史/收益依存/马尔可夫演化/最小充分划分; 换一套状态集=换一个均衡集, 警惕弱相关变量的大权力 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
