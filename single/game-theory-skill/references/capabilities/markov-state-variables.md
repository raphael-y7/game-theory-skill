# 马尔可夫状态变量（路由能力卡）

## R — 原文

> "在总结历史时,划分必须不能太粗糙。也就是说,在每一期,参与人必须能够由 $h^t$ 所属划分中的元素恢复出随后子博弈的策略元素:……**定义 13.5** 一个马尔可夫完美均衡是一个策略组合 $\sigma$,它构成一个完美均衡并且对于收益相关的历史是可测的。"(13.2.1)

> "随机博弈背后的思想是每期的历史都可以被概括为一种'状态'(例如,资本水平,信誉)。当期的收益取决于这种状态和当期的行动(例如,投资,价格,广告水平)。状态服从马尔可夫过程;也就是明天状态的概率分布由今天的状态和行动决定。"(13.1.1)

> "例如,如果我们在囚犯困境中加入一个'状态变量',它记录了参与人背叛的次数,并且允许这个变量对收益有任意小的影响,这时'总是合作'就成为一个 MPE 的结果。这说明 MPE 集不是上半连续的。"(13.2.3)

## I — 自述

这张卡回答长期跟踪问题：**盯住一个行业/公司，最少要看哪几个变量？哪些历史细节可以安全扔掉？**

状态变量的资格规则五条（逐项过滤候选指标）：①**概括性**——每期历史可被它概括；②**收益依存**——当期收益取决于状态与行动；③**马尔可夫演化**——明天状态由今天的状态和行动决定（可分离序贯博弈中 k^{t+1}=f(a^t)，无需回看全部历史）；④**充分性**——同属一块的历史其后子博弈策略性等价（行动空间相同+效用代表相同偏好）；⑤**最小性**——取最粗糙的充分划分（"收益相关的历史"）。按这五条过滤：**不满足(2)(3)的"历史细节"（如多年前的价格战次数）不该进最小状态集，除非它真的改变行动空间或偏好**。

一个反直觉警告：**选不同状态=选不同均衡**。重复囚徒困境取空状态 → 唯一 MPE 是每期背叛；但加入一个对收益影响任意小的"背叛次数"计数变量 → "总是合作"成为 MPE 结果——MPE 集对状态空间的选择不连续（非上半连续）。声称"只需跟踪 X"的简化模型，要先检查被扔掉的变量是否真的零收益相关。下半连续性保证（收益被扰动后仍存在主要依赖原状态的 MPE）是对"很难肯定哪些过去变量完全没有影响"的部分回应。

操作口径：行业跟踪清单 = 挑最小充分状态集（如产能存量、需求水位、声誉/份额），历史细节只在改变上述状态时才需要回看——这正是"只跟踪关键变量"的规范化；MPE 比子博弈完美更严格（要求行动不依赖对当前和未来支付无直接影响的过去），但代价是对弱相关变量的敏感性。

## A1 — 应用示例

**例1：遗产博弈的马尔可夫储蓄策略（worked_example, 13.1, c86）**
输入：代际遗产/资本转移博弈。
执行：状态=资本存量，策略对状态可测——储蓄/遗赠规则只依赖当期资本水平，不依赖家族历史细节。
结论：可分离序贯博弈中状态演化方程 k^{t+1}=f(a^t) 成立，历史可安全压缩。

**例2：公共资源开采（worked_example, 13.1, c87）**
输入：多家开采公共资源。
执行：状态=资源存量；马尔可夫策略=按存量定开采量；空状态之外的变量（开采历史）对当期收益无直接影响 → 不进最小状态集。
结论：公地悲剧的 MPE 刻画只需"存量"一个状态变量。

**例3：状态选择改变均衡集（worked_example, 13.2.3）**
输入：重复囚徒困境。
执行：空状态 → 唯一 MPE=每期背叛；加入对收益影响 ε→0 的"背叛次数"计数 → "总是合作"成为 MPE。
结论：同一博弈、两套状态、两个相反预测——状态变量选择本身是建模决策，不是客观事实。

## A2 — 未来触发

**情境**：为一个行业/公司设计跟踪清单（最少盯哪几个变量）；判断哪些历史信息可以安全忽略；审查简化模型（"只需跟踪X"）被扔掉的变量；把多期互动压缩为"状态+策略"以支撑持续跟踪；识别"弱相关变量承载大权力"的建模风险。

**语言信号**（中英）：状态变量、马尔可夫、跟踪指标、盯哪些变量、历史压缩、MPE、"最少要盯什么"、state variable, Markov, tracking variables, sufficient statistic。

**与相邻能力的区分**：vs 竞争格局卡（U2）——那张做一次性比较静态；本卡把多期互动压缩为"状态+策略"支撑持续跟踪。vs 合谋卡（U3）——那张的"正常/惩罚两状态"跟踪（Abreu 最优惩罚）是本卡原则的应用实例（另见）。vs 时机竞争（U7）——消耗战的"熬战状态"跟踪同理是应用实例。

## E — 执行

**输入契约**：待跟踪对象的动态结构（什么影响未来的收益/行动空间）；候选状态变量清单；每期可观察的数据。

**步骤**：
1. **找候选状态**：资本存量、产能、需求水位、声誉/份额、库存……凡是"概括历史且收益依存"的量。完成标准：候选清单。
2. **五条资格过滤**：逐变量过（概括性/收益依存/马尔可夫演化/充分性/最小性）——不满足收益依存与演化的历史细节剔除。**充分性的操作化**：同一状态值下，不同历史的后继策略集是否相同？无数据时用代理判断——该历史是否改变行动空间或偏好（改变→不充分，须保留；不改变→可压缩）。完成标准：过滤记录。
3. **演化方程检验**：演化分两类——**可控状态** k^{t+1}=f(a^t)（产能、库存、声誉，由行动递推）；**外生状态** s^{t+1}=g(s^t, ε^t)（需求、政策、技术冲击，由自身与随机冲击递推）。两类都满足马尔可夫性、历史均可安全压缩，但外生状态不可由行动控制——跟踪清单须分列两类。不可递推者 → 该"状态"不马尔可夫。完成标准：演化检查（可控/外生分类）。
4. **敏感性声明**：对被扔掉的弱相关变量做存在性检查——它对收益的影响是否真的为零？标注 MPE 非上半连续风险。完成标准：敏感性声明。
5. **输出**。完成标准：(a) 核心状态集（2-4 个变量）；(b) 每个变量的资格依据；(c) 历史回看触发条件（何时例外）；(d) 敏感性声明；(e) 无法排除的弱相关变量单列 watch 清单（不计入核心状态数），并声明其对均衡选择的敏感性。

**判停点**：候选变量与收益的关系无法判断时，核心状态仍限 2-4 个；无法排除的候选进入 watch 清单（不计入核心状态数）并标注待验证，不强行压缩到单变量、也不把 watch 变量塞进核心集。

## B — 边界

1. **状态选择是建模决策不是事实**：换一套状态集=换一个均衡集——同一博弈的 MPE 预测可因划界不同而相反（空状态 vs 计数变量）。
2. **MPE 集非上半连续**：对收益影响任意小的变量可承载均衡选择的大权力——"简化模型"的稳健性要单独论证。
3. **全部历史也是充分划分**：它不丢失任何均衡但"信息太多"——最小化的价值在可跟踪性，不在正确性。
4. **MPE 不覆盖声誉类现象**：声誉效应依赖参与人对过去行为中"与未来支付无关"部分的反应，MPE 划界会把它扔掉——声誉分析转声誉卡。
5. **技术性边界**：支付相关状态的确认（哪些博弈的 MPE 有良好性质）是高级专题（13.2），微分博弈（13.3）需连续时间工具，本卡不展开。
6. **作者盲点**：状态变量的实证选择（现实中哪些变量"真的"收益相关）超出理论框架；数据可得性约束不建模。
