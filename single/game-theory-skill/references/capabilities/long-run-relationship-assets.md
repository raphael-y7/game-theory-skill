# 品牌、平台与长期关系资产评估

## R — 原文

> "厂商之所以存在,准确地说,是提供一个长期参与人,他因为要考虑将来得到奖惩的前景而变得值得信赖。……当厂商有充分的耐心时,以下策略是一个子博弈完美均衡:厂商一开始在每次消费者购买的时候都生产高质量产品,而且只要他从未在过去生产过低质量产品,就一直这样持续下去。"(5.3.1)

> "如果在每阶段博弈中同时行动,短期参与人将在每一期欺骗,那么唯一的均衡结果就是双方总是欺骗。这暗示了将无名氏定理推广到这些博弈的方法是修改可行收益和最小最大值的定义以建立约束使得短期参与人总是作出短期最佳反应。"(5.3.1)

> "对于接近 1 的贴现因子,如果参与人观察到他伙伴前一期的配对结果,即他伙伴及其对手的选择,合作是一个均衡结果。……单独一个参与人的背离导致整个'社会'最终陷入全部背叛的均衡。"(5.3.3)

## I — 自述

这套方法回答：**品牌溢价、平台信誉、供应链关系这类"声誉资产"值多少钱、能不能自我维持？哪些行业是一次性博弈、质量承诺靠不住？**

核心是一句话：**声誉价值 = 未来关系租金流的贴现和 vs 欺骗一次的短期利得**。厂商之所以值得信赖，正是因为它是一个"长期参与人"——耐心的贴现加总使高质量路径的未来收益压过当期欺骗的利得，"一直高质量；一旦低质量就永久失去顾客"是子博弈完美均衡。品牌溢价本质是**重复博弈贴水**。

判断任何"长期对短期"结构（平台-商家、厂商-消费者、银行-储户）能否自我维持，查三件事：①**行动次序**——短期方先行动且能看到长期方全部历史（平台先展示评价、商家再入驻）⇒ 合作可为均衡；同时匿名行动 ⇒ 短期方每期欺骗，唯一结果是双方欺骗。②**观察口径**——只有混合策略公开可见时无名氏定理式结论才成立；只能看实现行动时均衡集可能严格变小，长期方受"沿路径各纯行动后继收益无差异"的效率上界约束。③**δ 的构成**——存续期长、品牌再投入大（声誉资产置于风险中）的公司有效耐心更高、更自律。

延伸到社群与随机匹配：一次性交易平台"以牙还牙"极脆弱（TFT 只在单点临界 δ=1/2 是均衡，δ 大了惩罚者自己不愿罚）；评分系统、黑名单共享、历史成交可查这类**声誉基础设施**是把一次性博弈接入长期的关键无形资产——"二阶声誉可见性"（能看到对手上期怎么对待别人）直接决定合作可行域。

输出：关系资产的估值口径 + 自我维持判断 + 一次性博弈行业的识别 + 声誉基础设施的资产化评估。

## A1 — 应用示例

**例1：长期厂商与短期消费者的质量声誉（worked_example, 5.3.1 例5.1, c38）**
输入：每期消费者先决定买/不买，厂商再选质量；高质量双方各得 1，低质量厂商得 2、消费者得 −1；不交易为 0。
执行：构造"厂商从未产低质则一直高质，否则永久低质；消费者从未见低质则一直购买"。验证：厂商耐心的贴现加总使高质量路径收益 1/(1−δ) 超过"骗一次得 2 之后永远 0"。
结论：δ 充分大时"始终高质量"是子博弈完美；δ 小则每期欺骗。老牌厂商的品牌溢价=重复博弈贴水；解释消费者为何偏好"能期望长期存在的厂商"。

**例2：行动次序决定合作（worked_example, 5.3.1 例5.2, c39）**
输入：序贯版重复囚徒困境——短期参与人先选 C/D 且被观察，长期参与人后选（匹配或欺骗）。
执行：δ→1 时"长期方匹配短期方历史"是均衡——短期方先行且无未来，不必被奖惩即合作；对照同时行动版本：短期方每期欺骗，唯一结果是全欺骗。
结论：信息结构（次序+可观察性）决定合作可行集。平台先展示历史后撮合 vs 匿名同时交易，合作关系的天壤之别由此而来。

**例3：随机匹配中 TFT 的脆弱性（worked_example, 5.3.3, c41）**
输入：随机匹配社群（下期换对手，对方看不到你本轮历史），囚徒困境收益。
执行：查 TFT 临界条件 g_s = δ·(合作收益−惩罚期收益)；δ<临界 → 惩罚威胁不足；δ>临界 → 惩罚者因坏历史传递而宁愿不罚。图4-1 收益下 δ*=1/2（单点）。
结论：除非 δ 恰取临界值，唯一的对称马尔可夫均衡是每期欺骗——一次性交易平台靠"以牙还牙"维持不了诚信，必须靠评分/中介/社区记录把单次博弈接入长期。

## A2 — 未来触发

**情境**：
1. 评估消费股品牌溢价的真实性：品牌是否对应可自我维持的质量承诺。
2. 评估平台股的核心资产：评分系统/商家关系/二阶声誉可见性的价值。
3. 判断供应链关系（长期协议、专用模具）是信任型还是投资型，以及破裂风险。
4. 识别"一次性博弈行业"（低复购、匿名交易、项目制）中质量承诺为何靠不住。
5. 评估公司把声誉资产置于风险中的动作（重资产质保、长期质保承诺、品牌再投入）是否可信。

**语言信号**（中英）：品牌护城河、平台信誉、复购、质量承诺、供应链关系、长期主义、声誉资产、信任成本、"这家公司敢不敢砸招牌"、brand equity、reputation capital、repeat purchase、relationship-specific investment。

**与相邻能力的区分**：
- vs 合谋与价格战（collusion-price-war）：那张管**同业对等者**之间的合谋；本卡管"一长期对众短期"的质量/关系合作，结构不同、可行集不同。
- vs 声誉与强硬表态（reputation-tough-talk）：那张是**威慑性**声誉（强硬吓退进入者，先验×期限）；本卡是**正面合作**资产（质量/诚信换复购）。
- vs 信号解读（signal-reading-pbe）：本卡判断关系资产的存量价值与可持续性；单次公告的信息解读归那张卡。

## E — 执行

**输入契约**（缺失先问）：
- 结构类型：谁是长期参与人、对手是固定还是每期更换
- 行动次序与可观察性：短期方能否看到长期方全部历史；交易是序贯还是同时匿名
- 收益参数：每期合作利润、欺骗短期利得、欺骗后损失
- δ 的构成：长期方存续概率、品牌/关系再投入、资金成本

**步骤**：
1. **分类判断**：这是同业合谋（转合谋卡）还是"一长期对众短期"（本卡）还是威慑声誉（转声誉卡）？完成标准：结构归类落盘。
2. **先问建模边界**：合作价值来自"怕被踢出未来交易"（重复博弈逻辑，本卡处理）还是资产专用性投资与经验积累（承诺/资本积累模型，本卡失真）？完成标准：价值来源归类。

   **混合价值来源拆分**：现实关系价值常同时来自两处——重复博弈（怕被踢出未来交易）与资产专用性投资（改变未来可行集）。二者要**分别估值再相加**：重复博弈部分用本卡租金流口径（未来合作利润贴现和 vs 欺骗一次利得）；专用性部分用承诺/资本积累模型口径（投资形成的可占用准租金、转换成本、未来可行集扩张）。输出中**标注各占比例**——比例决定哪套工具是主口径，也决定破裂时哪部分价值先蒸发（专用性部分沉没、声誉部分随关系终止归零）。

3. **查行动次序**：短期方先行动且可观察长期方历史 ⇒ 合作可行；同时匿名 ⇒ 每期欺骗。完成标准：次序判断。
4. **查观察口径**：混合策略是否公开可见；不可见时用式5.14口径（沿路径各纯行动后继收益无差异）修正收益上界。完成标准：口径标注。
5. **算声誉租金**：未来关系租金流贴现和 vs 欺骗一次利得之比，代 δ 构成（存续概率×时间偏好）。完成标准：比值与两分支判断。

   **δ 与复购率别混用**：复购率是**租金流量**（收益侧），进入"每期合作利润"；它不是长期方的耐心 δ。δ 的构成 = **存续概率 × 时间偏好**（折现），衡量"未来多值钱"。把复购率记进 δ 会同时错估分子（每期利润）与分母（贴现），是这类估值最常见的口径错误。

6. **盘点声誉基础设施**：评分系统、黑名单、历史成交可查、中介——把"单次博弈接入长期"的结构是否存在、是否是公司的独占资产。完成标准：清单+资产属性判断。
7. **输出结论**。完成标准：(a) 关系资产估值口径（租金流/欺骗利得比）；(b) 自我维持判断（可行/不可行/条件性）；(c) 一次性博弈行业识别（若适用）；(d) 稳健度（观察口径与 δ 敏感性）。

**判停点**：欺骗短期利得无法估计时，降级为定性判断（结构检查：次序+可观察+存续期），不给估值；若价值来源被判定为"投资学习型"，明确告知本卡工具失真并转承诺/资本积累框架。

## B — 边界

1. **混合不可观察时结论收缩**：只能看实现行动（看不到随机化概率）时，无名氏定理推广不成立、均衡集可能严格变小（FKM）；别把"理论上可合作"当成"实际会合作"。
2. **TFT 在随机匹配中几乎全面瓦解**：仅单点临界 δ 是均衡；"以牙还牙"作为一次性平台的治理机制是误用。
3. **传染均衡的脆弱性**：一人背离全社会背叛的均衡极端脆弱，噪声（误判）即可引爆；评估社群/行业自律时找"弹性"均衡（有限惩罚后回归）而非全有全无惩罚。
4. **末期效应不可忽略**：世代交叠组织中"最老一代必偷懒"——评价合伙制/老带新机构时先查末期安排；集体连带惩罚既维持自律也是组织脆弱点（误伤即崩塌）。
5. **重复博弈建模边界**：产能军备竞赛、研发学习等"行动改变未来可行集"的现象不属于本卡（那是承诺/资本积累模型）。
6. **对手不给你暴露行动的机会**：行动不可观察或对手先发制人时，声誉机制失效——"对手不给你机会建立声誉"是真实风险（质量博弈反例）。
7. **"一次性博弈行业"不是二值判断**：同一行业内不同 segment 可分别为一次性（加盟/项目制/一次性大额交易）与重复（直营/会员制/订阅）。必须**分段判断**，按 segment 各自的复购结构与可观察性分别给结论；用行业整体标签（"这行低复购"）一刀切会同时误判两端。
8. **作者盲点（阶段0批判）**：本书不建模消费者端的行为偏差（品牌可能有非理性的情感溢价）、也不建模广告营销对声誉的替代或放大；监管与法律执行是声誉之外的另一层质量保障，本卡不含。
