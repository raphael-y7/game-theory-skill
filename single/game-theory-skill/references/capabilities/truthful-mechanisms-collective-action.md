# 说真话机制与集体行动（路由能力卡）

## R — 原文

> "在不要求预算平衡时,任何公共产品的有效供给机制都是可实施的,甚至更强的结论也是成立的:有效供给机制是优势策略可实施的。道理很简单:总可以适当选择参与人i的转移支付,从而使得代理人i的收益等于参与各方的总剩余(常数)。"(7.4.3)

> "这一结果从直观上看是非常简单的。如果代理人很多,则代理人成为决策中心人物(即 $\hat{\theta}_i$ 的改变会导致 $x$ 的改变)的概率就非常小,如果代理人是连续分布的,则这一概率就为 0。这样,代理人 $i$ 的目标就简化为使他获得的期望转移支付最大,即使他对公共产品的期望贡献最小化。"(7.4.6)

> "罗布(Rob,1989)与梅勒斯和波斯尔思韦特(Mailath and Postlewaite,1990)证明了当 $I$ 趋于无穷时,如果 $c > \underline{\theta}$ 且 IR,IC,BB 得到满足,则公共项目被执行的概率趋于 0。"(7.4.6)

## I — 自述

这张卡回答：**股东监督/行业自律/联合减产/公共投入为什么总是失败？什么样的规则能让参与者说真话、让集体行动自发达成？**

人多时方向相反，分水岭是**关键人物概率**——单个参与者改变结果的概率有多大：

- **私人品市场**：人数多 → 单人说谎改变不了自己的成交条件，只会降低成交概率 → 谎报无利可图 → 大市场近似有效（Roberts-Postlewaite 极限；Wilson 双边拍卖极限）。人多是解药。
- **公共品**：人数多 → 每人成为"关键人物"（报告改变供给决策）的概率 → 0 → 个体目标退化为最小化自己的期望贡献，贡献被封顶在最低类型 θ̲ → 期望收入入不敷出 → 有效供给概率趋于 0（即使"每个人受益都超过人均成本"）。**人不是解药是病灶**。补救口径：人均外部补贴 ≈ c−θ̲，或找到有强制力/能排除搭便车者的一方。

让参与者说真话的两条构造路线：**Groves 机制**——让每人的转移只依赖他人报告（内化社会总剩余），说真话成为优势策略，代价是一般不满足预算平衡（绿-拉丰：类型空间不加限制时它是唯一优势策略说真话机制）；**AGV 机制**——把转移换成"他人剩余的条件期望+均摊分摊项"，在贝叶斯 IC 下**效率与预算平衡可以兼得**，但只是贝叶斯激励（依赖共同先验）。取舍原则：优势策略机制稳健（不依赖对手信念）但可实施集大幅缩小；拟线性+类型独立+MLRP+分离条件同时成立时可免费兼得（Mookherjee-Reichelstein）。

公共项目的供给阈值也含租金调整：**Σ[θ_i − (1−P_i)/p_i] ≥ C(I) 时才供给**——真实剩余加总超过成本仍可能被信息租金项否决。

## A1 — 应用示例

**例1：Groves 机制的数值走查（worked_example, 7.4.3, c59）**
输入：2 人，θ₁=8、θ₂=3，公共品成本 c=10。
执行：谎报 θ₁'=2 → Σθ̂=5<10 → 不供给得 0 < 如实报的 1；谎报抬高也一样 → 说真话是弱优势策略。
结论：关键人物付费式机制让决策者内化他人剩余；但 t₁+t₂=−9≠0——委托人（或第三方）必须出钱，预算不平衡。

**例2：AGV 预算平衡核算（worked_example, 7.4.3）**
输入：I=2，V_i=θ_i·x，θ~U[0,10]。
执行：t_i 取"他人剩余的条件期望−均摊项"→ E[t₁]=E[V₂]−E[V₁]=5−5=0、E[t₂]=−E[t₁]。
结论：贝叶斯 IC 下效率+预算平衡兼得；但只是贝叶斯激励——对手不说实话时说谎可能有利。

**例3：公共品强无效率（worked_example, 7.4.6, c62）**
输入：I=1000 人，θ_i~U[0,1]，工程人均成本 c=0.8>θ̲=0。
执行：按 Rob-Mailath-Postlewaite 极限——关键人物概率→0，贡献封顶 θ̲=0，期望收入 0 < 成本。
结论：项目被执行概率趋于 0；实施有效机制需人均外部补贴 ≈ c−θ̲=0.8。"人人受益但无人买单"在大群体中是定理不是巧合。

## E — 执行

**输入契约**：产品性质（私人品/公共品/混合）；参与人数与分布；成本结构与分摊方式；有无预算平衡约束；有无外部强制或补贴来源。

**步骤**：
1. **关键人物概率判断**：单个参与者能改变结果吗？（私人品：能否影响自己的成交条件；公共品：报告能否改变供给决策）——概率趋 0 的方向决定人多是好是坏。**长期重复博弈分支**：若集体行动在重复互动中进行（行业协会长期存在、成员反复相遇），本卡的一次性结论可能翻转——转 monitoring-cooperation-discipline 卡，按贴现因子 δ 与行为可观察性评估合作能否自我维持。完成标准：双向定性判断。
2. **四格定位**（预算平衡×效率地图）：无 BB+IR 弱 → Groves/AGV 可行；BB+IR 都硬 → 必无效率（MS 型）；私人品+人多 → 效率恢复；公共品+人多 → 更糟。完成标准：落格。
3. **租金调整阈值**（若供给判断需要）：检验 Σ[θ_i − (1−P_i(θ_i))/p_i(θ_i)] ≥ C(I) 是否成立——P_i 为参与人 i 的类型分布函数、p_i 为其密度，(1−P_i)/p_i 为逆风险率（信息租金项），C(I) 为工程总成本；出处：7.4.6 式 7.27。完成标准：供给判定。
4. **机制构造**（若需设计）：有效规则 → Groves 转移（优势策略、不 BB）或 AGV（贝叶斯 IC、可 BB）二选一；有委托成本时用虚拟问题均摊。完成标准：转移规则。
5. **补贴/强制判断**：人均外部补贴 ≈ c−θ̲ 是否可得（口径：c=C(I)/I 为人均成本，非边际成本）；有无强制力方。完成标准：融资来源判断。
6. **输出**。完成标准：(a) 集体行动前景判断；(b) 说真话机制设计（若适用）；(c) 补贴/强制需求量级；(d) 边界（先验依赖、类型空间）。

**判停点**：类型分布未知时按方向性结论输出（人多→私人品有效/公共品失效），不算阈值；无外部资金来源且 IR 硬约束时直接判"自发集体行动不可行"。

## B — 边界

1. **Groves 不满足预算平衡**：绿-拉丰唯一性——想不靠补贴又说真话且优势策略，做不到；看到"既无补贴又号称优势策略说真话"的制度要查它的真实激励来源。
2. **AGV 只是贝叶斯激励**：依赖共同先验、对手不说实话时说谎可能有利——比优势策略弱一档。
3. **优势策略机制的代价**：可实施集大幅缩小；"免费兼得"需要 MR 条件（拟线性+独立+MLRP+分离）全部成立。
4. **大数结论有技术前提**：独立类型、拟线性、均衡策略可微有界导数；类型相关或风险回避时结论要重验。
5. **无 IR 约束的例外**：脚注129——失效根源在参与约束而非信息本身；强制方（税收）可绕开。
6. **团队道德风险的入口形态**：产出平分+成本自担 → 努力是严格劣势策略（1/n 摊薄）；检查激励是否对冲摊薄效应是反推起点。
7. **作者盲点**：不建模沟通与重复互动（那是监督卡的地盘）；组织行为学的解决之道（企业文化、身份认同）不在框架内。
