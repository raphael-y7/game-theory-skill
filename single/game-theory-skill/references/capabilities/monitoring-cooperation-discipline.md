# 监督结构与合作纪律（路由能力卡）

## R — 原文

> "何时能得到无名氏定理,关键在于有多少关于参与人行动的信息一定能用公共结果显示出来。如果参与人得不到任何他人选择的信息,唯一的均衡收益将是静态均衡收益的凸组合;当行动本身被观察到时,在适当的'充分维数'条件下就能得到无名氏定理。"(5.6)

> "$a$ 是可实施的,只要对任何参与人 $i$ 都不存在行动 $a_i'$ 使得 (ⅰ)$g_i(a_i', a_{-i}) > g_i(a)$ 和 (ⅱ)$\pi_{\cdot}(a_i', a_{-i}) = \pi_{\cdot}(a)$。"(5.6)

> "无论利率如何,$v^* > 0$ 的必要条件是……也就是说,'没有成功'的似然率 $L(\tau) = e^{-(\mu-\lambda)\tau}$ 应该充分大。不过随着 $\tau$ 收敛到 0,似然率 $L(\tau)$ 收敛到 1:因为几乎可以肯定将没有成功,公共观察到的结果提供的信息太少以至于没有均衡能改善最小最大值。"(5.7)

## I — 自述

这张卡是合谋卡（collusion-price-war）的**深化层**：当背离不可观察、不可归因时，先过这里的信息结构检查，再回去算 δ 阈值。

核心纪律一句话：**偏离若不可统计归因就不可惩罚——先查公共信号能否区分"谁在背离、是背离还是冲击"，再谈耐心**。可执行检查按序三步：①**信息量谱系**——零信息（看不到对手信号）→ 均衡收益只能是静态均衡的凸组合，无合作；完全观察 → 充分维数下无名氏定理成立；中间态 → 走满秩检查。②**隐身偏离检查**（充要）——存不存在"收益更高且结果分布完全相同"的偏离？存在 → 一切基于该公共指标的奖惩失效（结果分布相同 ⇒ 后继收益相同 ⇒ 无法用未来区分）。③**满秩检查**（便于计算的充分条件）——个人满秩（各人行动导出不同分布）保证"是否背离"可识别；两两满秩（两人的偏离统计上可区分）保证"罚一人必奖另一人"的零损耗惩罚可设计。

两个反直觉结论要单独记住：**合伙困境**——产出只依赖行动之和（共同KPI）的结构里"谁偷懒"不可归因，对称均衡必须相互惩罚，有效率合作无论 δ 多大都不可近似实现（例5.4：收益之和被压在 2 以内，有效值 5/2 不可达）；**高频监控悖论**——考核间隔缩短（τ→0）使单期信号变稀（"没成功"似然率→1），监督反而失去区分力，合作必要条件 g/c ≤ e^{−(μ−λ)τ}−1 在 τ 小于阈值时无解。

方向性工具：Blackwell 信息变差定理——新监督 = 旧监督+噪声 ⇒ 均衡收益集**严格**缩小。降低透明度的制度变化（合并披露口径、延迟发布、改汇总通报）是合作纪律的确定性削弱信号。

## A1 — 应用示例

**例1：重复合伙博弈的效率损失（worked_example, 5.6 例5.4, c45）**
输入：两人选工作/偷懒，平分产出（好=8/坏=0），努力成本1；好产出概率 9/16（双工作）、3/8（单工作）、1/4（双偷懒）。
执行：个人满秩成立但两两满秩失效（产出只依赖行动之和）；激励相容要求后继收益差 v_g−v_b ≥ [(1−δ)/δ]·(4/3)。
结论：两人都工作的策略得到 (5/4,5/4)——这是**最高的对称可行收益**（不是均衡收益）；均衡的收益之和被限制在 2 以内，有效 (5/2) 不可近似实现——无论 δ 如何。合资企业/共管基金的"共同KPI"结构价值上限受压，改善方向=分账/独立核算/过程审计。

**例2：APM 泊松合伙——观察频率与合作消失（worked_example, 5.7, c46）**
输入：工作强度 5、偷懒强度 3（λ−μ=2），考核间隔 τ=0.1，项目收益比 g/c=0.5。
执行：算似然率条件 g/c ≤ e^{−(μ−λ)τ}−1 = e^{0.2}−1 ≈ 0.22 < 0.5 → 条件不满足。
结论：高频考核下没有均衡能优于静态背叛——监督频率不是越高越好，单次观察的信息密度比频率更根本。

**例3：Blackwell 变差判定（worked_example, 5.7, Kandori）**
输入：监督制度从"逐笔交易可见"改为"月度汇总通报"。
执行：检验新分布能否由旧分布加噪得到——汇总可由明细加噪生成 → 信息严格恶化（Blackwell 混淆序）。
结论：均衡收益集严格缩小，行业合作/合谋可持续性确定性下修。

## A2 — 未来触发

**情境**：评估行业信息透明度能否支撑卡特尔/联盟；设计或评价共同 KPI 的合资/合伙结构；分析高频考核为何反而毁掉合作；评估信息披露规则改动对行业合作的影响；判断"只报总量"的行业数据能否支撑纪律。

**语言信号**（中英）：信息透明度、监督结构、背离归因、共同KPI、搭便车、考核频率、数据披露、满秩、monitoring structure, attribution, information quality, likelihood ratio, partnership incentive。

**与相邻能力的区分**：vs 合谋卡（U3）——那张以可观察合谋为主（含公共信号/触发价格分支），管 δ 阈值与价格战机制；本卡管信息结构本身能否承载奖惩。vs 信息结构敏感性卡（U15）——本卡是重复博弈内的监控技术；那张是均衡层面对信息结构冲击的敏感性。

## E — 执行

**输入契约**：公共信号的清单（谁能看到什么）；结果分布与行动的关系（产出=各自行动之和？还是可归因？）；行动数与结果数；考核周期 τ 与信号强度参数（如可得）。

**步骤**：
1. **审计信息结构**：公共结果是什么、能否统计区分"谁在背离"与"背离 vs 冲击"。完成标准：信号清单+可区分性初判。

   **信息量谱系三档**：①零信息（看不到对手任何信号）；②**噪声聚合公共信号**——结果 = 行动 + 噪声（如只看总销量、只看合并报表），既非零信息也非完全观察；③完全观察。第②档不要停在"中间态"标签上，直接走步骤3满秩检查，并**预期效率损失**（合伙困境型：对称均衡须相互惩罚，有效收益不可达）。

2. **隐身偏离检查**（充要）：找"收益更高且结果分布相同"的偏离。存在 → 该公共指标无法承载奖惩，设计终止或换指标。完成标准：检查记录。

   **近似隐身筛查**：除"分布完全相同"的二元判定外，再加**信噪比筛查**——若偏离导致的结果分布与基准分布的 KL 散度/似然比接近 1（信号几乎不可分），按**近似隐身**处理：形式上可识别，实际上无法支撑奖惩。处置同上——增加结果维度（分账/过程审计）或**聚合多期**提高信噪比。只做二元检查会漏掉"统计上勉强可分、经济上无用"的中间地带。

3. **满秩检查**：个人满秩（各行动分布行线性无关；结果数≥行动数）；两两满秩（摞接矩阵秩=|A_i|+|A_j|−1）。**连续/聚合信号的操作程序**：先记**维度账**（结果数≥行动数是必要条件），再用引理做定性判定——**对称组合（两人同向偏离）必然失效、附近非对称组合通常可行**（见B4），故结论按组合逐个报，不报"整体可/不可"。完成标准：秩计算或定性判定+组合清单。
4. **监控节奏检查**：区分两种 δ→1——"耐心变大信息不变"（合作区间扩大）vs"间隔缩短信号变稀"（APM 悖论，合作消失）；算似然率阈值。完成标准：节奏归类+阈值核算。
5. **给出修复方向**（若失效）：非对称监督策略（Legros：一人工作一人混合）；增加结果维度（分账、过程审计、个体可验证记录）；多期聚合再触发（拉长有效 τ）；显式治理替代自我执行。完成标准：修复清单。
6. **输出**。完成标准：(a) 信息结构可支撑性判断；(b) 隐身偏离清单；(c) 监控节奏建议；(d) 修复方向与优先级。

**判停点**：结果分布无法估计时，按结构特征定性判定（"产出只依赖总量"→必然两两满秩失效）；信号参数缺失时输出结构检查表而非数值结论。

## B — 边界

1. **零信息结构无合作**：看不到对手任何信号时，均衡收益只能是静态均衡凸组合——别指望"耐心"补救信息缺失。
2. **共同KPI的合伙结构天然低效**：产出只依赖行动之和 → 对称均衡必相互惩罚，效率损失是结构性的；改善要靠归因性提升而非加大惩罚。
3. **高频≠强监督**：单期几乎无信息的高频考核摧毁激励相容；拉长考核期或累积证据再触发。
4. **满秩是"几乎处处"而非处处**：个别组合可能失效，附近非对称组合往往可行；结论按组合逐个验证。
5. **信息变差的严格性**：Blackwell 恶化单调缩小均衡集，但"严格缩小"的幅度依赖收益结构——方向确定、幅度需算。
6. **建模口径**：本框架要求各人收益只依赖自己行动与公共结果；收益泄露对手私人信息时公共性破坏。
7. **作者盲点**：本书不建模监督的技术成本与组织政治（增加披露本身有阻力）；归因技术与会计/审计实务的对接需要外部知识。
